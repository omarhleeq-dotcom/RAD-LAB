# RAD-085 — مصفوفة المحو والاحتفاظ

## السلطة والحالات المختلفة

الأصل الحاكم: [C2](DECISIONS.md#rad069c2-owner-2026-10-24)، [تصحيح Terms يوم DB day](DECISIONS.md#rad069-db-day-owner-2026-10-24)، [النصان الأصليان لـTerms](../messages/ar.json)، [سياسة Assess كاملة](ASSESS_RETENTION_POLICY.md)، [S-ASSESS-15](DECISIONS.md#assess-retention-owner-2026-10-20)، و[قرار هذه الجلسة](DECISIONS.md#rad085-erasure-owner-2026-10-26). [S-PILOT-15 التاريخية](archive/decisions/DECISIONS-until-2026-10-16.md#decision-s-pilot-15) تظل دليل الأسئلة العامة غير المحسومة؛ لا نستبدل بها النص المعتمد لاحقًا.

- **طلب فردي:** بعد تحقق الملكية يبدأ المالك التعطيل فورًا، دون انتظار نهاية التجربة أو الأشهر الستة. نافذة الاستعادة30يومًا؛ finalise بعدها فقط، عبر C2. لا حذف النفس/آخر مالك ولا إدارة حسابات للمشرف. الحجب الجديد يبقي التعطيل ولا يعدّل تاريخ الطلب أو يمنح احتفاظًا دائمًا.
- **نهاية التجربة:** يعلنها المالك بعد اكتمال المشاركات ومراجعتها عبر الموقع أو البريد. تحذف البيانات المرتبطة بالمشاركين خلال ستة أشهر من الإعلان؛ قد تبقى إحصاءات وملخصات عامة لا تحدد الهوية لتحسين الاستخدام أو البحث العلمي. لا إعلان نهاية مفترض، ولا purge عام أو تجميع جديد بهذه الدفعة.
- **سحب المشاركة/المغادرة:** يوقفان الرؤية المشتركة في نطاقها، ولا يساويان حذف الحساب أو النتائج أو Practice. إعادة القبول/الانضمام لا تعيد نافذة الرؤية الماضية. لا إلغاء امتحان أو targets مثبتة لمجرد السحب.
- **انتهاء المجموعة:** يحجب وصول المشرف، ولا يحذف النتائج لدى المالك أو الطالب ولا يعيد احتساب موعدها. إغلاق الإسناد يمنع بدءًا جديدًا ويبقى نهائيًا، ويختلف عن نهاية المجموعة وتعطيل Assess.

«محو الحساب» أدناه يعني finalise المستحق بعد30يومًا أو replay مثبتًا لحذف نهائي سابق أثناء حجر restore. إجراء إعادة التطبيق الخاص ليس API لتجاوز النافذة. «خاص» لا ينفي وجود بيانات شخصية داخل نص حر؛ لا تنقل الأسماء أو المراجعين إلى سجل الإثبات.

## أثر قرار المالك الأحدث وحالات الكاتب المحجوبة

[قرار2026-10-26 الأحدث](DECISIONS.md#rad085-owner-final-local-2026-10-26) حسم اتجاه الحفظ ونقل **مسؤولية الإدارة** للمالك وإزالة هوية المنشئ حيث يمكن؛ لم يُنفذ نقل SQL بعد. أوصاف «يحجب/لاحقًا» في جرد التنفيذ أعلاه تصف الحارس المحلي القائم، ولا تعيد سؤال المالك عن أصل القرار.

| الحالة | الإجراء المسموح/القائم | العائق المحدد قبل نقل/محو الهوية |
|---|---|---|
| طالب فقط | C2 يمحو بياناته بعد المهلة ويحفظ امتحانًا ونتائج زملائه؛ تكرار ومصالحة وrollback بالشواهد | نسخ/صادرات/إبطال المزوّد لاحقًا؛ ليس حذفًا حيًا مثبتًا |
| كاتب محتوى خاص غير مسند لا حقوق/مراجع للغير فيه | الملحق المحلي يمحو reviews غير المؤكدة وlinks/publications الخاصة ثم CASCADE القائمة؛ لا نقل شامل للمالك | إذا وُجد أثر للغير أو provenance غير متطابقة يتوقف بدل فك المرجع |
| منشئ امتحان مسند مفتوح | يجب حفظ النسخة والإسناد ونتائج الآخرين ونقل الإدارة فقط | owner_id/كاتب/group/scope/confirmed review مراجع مترابطة، ولا مسار نقل مأذون SQL حتى استثناء جديد. لا ينقل Practice/surveys/الملاحظات الشخصية أو حساب الكاتب |
| امتحان/إسناد مغلق نهائيًا | يبقى closed_at والنسخة والإصدارات والنتائج دون إعادة تصحيح أو فتح | assignment_terminal_v1 تمنع تغيير owner_id للمغلق؛ تجاوزها أو تعطيلها ممنوع. يلزم فصل مسؤول الإدارة عن provenance وتحديد فرق محمي جديد |
| مجموعة مشتركة أو قرار مشرف أو تعيين أداره للغير | بيانات الآخرين والعضوية/الفترات/الطلبات والإسناد محفوظة | guard_managed_group_v1 تمنع تغيير owner/supervisor؛ appointed_by/decided_by وassignment_scopes مراجع هوية بلا مسار إزالة معتمد تنفيذيًا. لا تجعل المالك مؤلفًا أو مشرفًا جديدًا ضمنيًا |
| مستند مثبت/نسخ/حزمة مراجعة بها اسم مؤلف/مراجع أو بيانات شخصية | أقل بيانات لازمة فقط؛ لا نسخ تلقائي إلى المالك أو دليل المصالحة | المستندات الحرة قد تتضمن إسنادًا واجبًا وبيانات غير لازمة. source/digest/نسخة النشر مثبتة؛ تعديلها بصمت يخرق الإصدار والمرجع. لا فحص نصي آلي يثبت خلوها أو ترخيصها |
| محتوى بإسناد مطلوب بالترخيص أو حقوق غير موثقة | لا تحذف الإسناد المطلوب ولا تنسبه للمالك؛ التعطيل باقٍ والحذف النهائي محجوب مؤقتًا | السؤال المركز للمحتوى الحقيقي: **ما الإسناد الذي يشترطه ترخيص كل امتحان يجب حفظه، وما بيانات المنشئ التي يلزم إبقاؤها لتحقيقه؟** يلزم دليل المصدر/الرخصة وتحديد الحقول، لا اعتماد قانوني مخترع أو إبقاء كل الهوية احتياطًا |

لا يعني غياب ملف محتوى حقيقي مراجع إذنًا بنقل المحتوى الصناعي بوصفه مرخصًا. النقل الإداري قد يسمح للمالك بالإغلاق وإدارة الإسناد، لكنه لا يسمح بتحرير publication مثبتة أو إعادة نسبتها، ولا بسحب targets أو حذف نتيجة طالب آخر. التزامن يجب أن يحتفظ بترتيب scope→profiles→versions، ويرفض تغير الجرد/revision أو FK أو الإغلاق بين المعاينة والتنفيذ، ويرجع المعاملة كلها عند أي فشل؛ هذه **متطلبات تنفيذ لاحق** وليست اختبارات نقل منجزة. شواهد الطالب/الخاص/الحجب والتكرار والعزل/التزامن/rollback القائمة تبقى دليلًا لحدودها فقط.

## حد القرار

لم يتغير أي حكم قديم باختصار هذه المصفوفة، وروابط أصوله باقية. الجديد هو [قرار المالك المحدد](DECISIONS.md#rad085-erasure-owner-2026-10-26): الحجب المؤقت، والمحو التابع الآمن، والاستثناء الأدنى للمصالحة. لا موافقة قانونية أو تخزين معتمد بالنيابة. قرار نقل مسؤولية الإدارة وإزالة الهوية حيث يمكن معتمد الآن بالمرجع الأحدث، أما تطبيقه التقني ومراجعة الحقوق فما زالا محجوبين بما سبق. الحجب لا يحل التزامات Terms تجاه الكاتب؛ يلزم قرار ومراجعة قبل بيانات حقيقية.
