# RAD-085 / P2-UI — معاينة full-practical بالمشهد القائم

## 1. الانحرافات والميزانية

الهدف الواحد: استكمال المعاينة المحلية بالمشهد القائم، مع فصلها عن mixed ومنع تسريب بيانات التقييم. الميزانية المعلنة صُححت قبل التحرير من29إلى30ملفًا عند عد اعتماد shoulder-model؛ استُخدم29ملفًا بعد إسقاط hand-visual غير اللازم. القائمة:5ملفات geometry قائمة و3ملفات radiograph قائمة،9مستهلكي رسم/نموذج، drawing-data جديد، StudentPreview وcopy واختبار practical، اختبار scene جديد، سكربت التدقيق، الخطة والحالة وHANDOFF وهذا التقرير، ولقطتان. لا تعديل لحارس الاستيراد أو validators أو خدمة/قاعدة، ولا worktree أوsubagents.

تحقق docs:context لـ#137 منopen/Draft/unmerged، وجُلب main ورأس PR الفعلي قبل العمل؛ كانا31e9cbf وb52d410 على الترتيب، دون افتراض الرأس من التسليم السابق. بداية checkout كانت main فظهرunknown task؛ جُلب فرع PR الصريح واستُكمل في checkout نفسه ثم نجح status:summary لـRAD-085 والمهام ذات الصلة. لا إنشاءPR بديل. استُعيدت الاعتمادات من القفل بـnpm ci --ignore-scripts دون تغييرpackage/lock.

## 2. المنجز والمستبعد

PracticalScene القائم مع PracticalControls القائمين يعملان داخل معاينة full-practical؛ كلاهما يقرأ ويعدل القيم المؤقتة نفسها. العرض لا يستقبل draft أوadapter؛ الإسقاط الصريح في draft.ts باقٍ دون توسيع. المعاينة تعرض بندًا واحدًا، والتنقل يحفظ إعداداته مؤقتًا؛ الإغلاق والتبديل وفقد الرؤية يمحوانها. فصل mixed والتحقق من المراجع والحفظ والإسناد المصفح والإلغاء وحراسة الردود المتأخرة باقية.

فُصلت إطارات الرسم وأبعادها ومقاييسها ونطاقات الإزاحة فقط عن ملفات الفحوص والصور. الملفات الأصلية تعيد استخدامها وتحتفظ بـtargetPx والأهداف والمصادر والترخيص والملاحظات وreview؛ لم تُنقل إلى مصدر الرسم العام أوDTO الطالب. نطاق الراحة البصري للكتف بقي داخل نموذج الرسم القائم مستقلًا عن ثابت نطاق التقييم الأصلي الذي بقي في ملفه؛ دلالته وسلوكه العددي لم يتغيرا. الرسم القائم يُظهر أثر النموذج نفسه؛ لا حل أو تلميح أو مسار تصحيح جديد.

لا رسومات/محرك موازٍ، ولا حالة أو فحص أو صورة أو تقييم جديد. لا محاولة أو تعريض أو حفظ إجابات أوتصحيح عبر الخدمة، ولا publication قابلة للتثبيت أو مراجعة/ترخيص/اعتماد طبي مخترع. لا SQL أوmigrations/RLS/checks أو اختباراتdatabase جديدة أوRPCs أوتغيير ربط حي أوSupabase/variables أوعامل أو نشر أوhosted preview أو مسار/قائمة منتج.

## 3. حسب المهمة

RAD-085 تبقىreview/waiting_on owner دونcompletion_evidence. تقييم المالك لواجهتيP1/P2 والهاتف في **آخر جلسة تجهيز الواجهات، قبل جلسةSQL المجمعة مباشرةً**؛ مؤجل وليس قبولًا أو اكتمالًا ولا يُطلب الآن. كلSQL واختباراته الجديدة في جلسة أخيرة واحدة بعد تجهيز الواجهات ومراجعة المالك. بقية المهام وملاحظاتها محفوظة؛ لا اكتمال للتأليف أو الإسناد أو صلاحيات المشرف الحقيقية.

## 4. المشترك وScale وإثبات الفصل

[drawing-data](../src/features/positioning/drawing-data.ts) مصدر مشترك للرسم القائم، دون runtime imports أو بيانات تقييم/أصول. [StudentPreview](../src/features/authoring-review/StudentPreview.tsx) يركب المشهد والضوابط؛ Session يدير النطاق والإلغاء والمسح؛ synthetic هوadapter الذاكرة؛ catalog يعمل فيNode. لا تغيير لعقدPracticalView أوFullPracticalRunner أوخدماته أوvalidators. حارسbrowser imports الأصلي باقٍ حرفيًا، مع اختبار bundle مستقل جديد.

أُخذت قبل التعديل نسختان مؤقتتان: JSON كامل لـCASES/EXAMS، وHTML للمشهد القائم لكل 17حالة عند الدوران الابتدائي وحديه الأدنى/الأعلى،51عرضًا. بعد الفصل نجحتcmp للنسختين byte-for-byte. SHA256 للسجلات `d5f7f73bba3e636c42978a0be625d3273140b5d005ab2093dc7b6f035637de62`؛ وللمشاهد `20c1d398016d55ff04f46d1b6c6a61616e8fd7fe4b50e8bb08922c02e6c492b0`. الأدلة المؤقتة تحت/tmp/rad085-before-* و/tmp/rad085-after-*؛ ليست بصمات محمية جديدة أو تجديدًا لتوقعات المستودع.

السقوف القائمة محفوظة: صفحة20،200بند و128KiB،مسودة حالية واحدة لكل حساب/مجموعة في الذاكرة، snapshot اصطناعي داخلي≤1000. لا تحميل الجميع للخدمة أوIDs مجموعات/مشرفين ثابتة. بيانات الرسم تغطي السجل القائم فقط؛ إضافة أسرة تتطلب عقدها ودليلها وتدقيقها، دون رفع التجميد. الكتالوج الصغير المشتق من السجل يحتاج بحثًا وpaging خادميين عند النمو. لا ضمان سعة120مستخدمًا أو سياسةاحتفاظ إنتاجية من الذاكرة.
