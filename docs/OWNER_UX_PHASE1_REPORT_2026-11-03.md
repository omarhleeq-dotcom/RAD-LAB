### خريطة الأقسام القديمة إلى الجديدة (لا شيء محذوف)

| القديم | الجديد |
|---|---|
| لوحة الطوارئ أعلى كل تبويب | زر أحمر «إيقاف طارئ» في الشريط بكل تبويب → «السلامة والسجل» مفتوحًا عند القسم نفسه دون تغيير |
| سجل الطوارئ | داخل القسم نفسه، مطوي |
| المشاركون: الصفوف والاعتماد/الإيقاف والتفاصيل والنشاط | الطلاب: صف (اسم + حالة)؛ النقر يفتح التفاصيل: البريد والرمز والتسجيل والنشاط والإجراءات |
| تعطيل الحسابات وحذفها: قائمة + تعطيل | زر «تعطيل» داخل تفاصيل الحساب بالتأكيد نفسه |
| بانتظار الحذف + استعادة + finalise | الطلاب ← مرشح «بانتظار الحذف» |
| جولات الاستبيان | تبويب الاستبيانات (المكون دون تعديل) |
| تعيين المشرفين (P1 أسفل الصفحة) | الطلاب ← «المشرفون»؛ زر «تعيين مشرف أو سحب الإشراف» في التفاصيل يفتحه مبحوثًا بالبريد |
| التدريب والتصدير | نتائج التدريب: مرشحات مطوية، سطر لكل فحص يتوسع لأكثر البنود خطأ، المحاولات/الملاحظات/CSV كما هي |
| Assess: المجموعات والأعضاء | تبويب المجموعات |
| Assess: الإسناد واختيار الطلاب/المجموعات | Assess ← إسناد اختبار (الإصدار ← المجموعات ← بحث الطلاب ← نشر) |
| إغلاق الإسنادات + إدارة المستهدفين | Assess ← الإسنادات المنشورة |
| تصحيح الأجوبة الكتابية | Assess ← التصحيح (العدد في العنوان والشريط) |
| محتوى/أسئلة Assess | Assess ← الأسئلة والمحتوى |
