## 2. المنجز وجرد الدورة

| الحد | التنفيذ |
|---|---|
| مسودة→revision | إعادة استخدام P2. الحفظ الناقص لا يصنع اعتمادًا؛ طلب الجسر يأخذ id/revision فقط، بلا actor أو digest متصفح |
| مراجعة مستقلة | authoring_reviewed_packages خاص/RLS دون منح جداول، وفارغ افتراضيًا. الحزمة تغطي digest لنسخة SQL نفسها؛ حقول authoring لا تصنع المراجعة |
| تحقق خادمي | مقارنة الهوية والإصدار والمسار والاسم والسياسة والبنود والمفاتيح والنقاط والمراجع، ثم validateMixedContent/validatePracticalContent القائمتين |
| المرشح والتثبيت والربط | content_submit_v1 نفسه، ثم wrappers محصورة بالمرشح المأذون، و installMixedContent/installPracticalContent القائمتان. bind يثبت تطابق الكاتب والنسخة والمحتوى و installed/available و practical presentation، ثم draft/revision/digest داخل المعاملة نفسها |
| المصالحة | receipt قراءة بلا كتابة مجال، تنتهي rollback. لا إعادة mutation آلية بعد ACK مفقود؛ replay الصريح يعيد version نفسها بعد التفويض والتحقق، دون إعادة نشر |
| الإسناد | prepare/targets/confirm عبر RPCs القائمة، مع operationUUID محفوظة عند ACK مفقود وصفحات 20. الأسماء من SQL، والوقت من serverNow. تعيد SQL فحص snapshot/revision والعضوية والموافقة والانتهاء والصلاحية |
| الإغلاق | assignment_page_v2 و closed_at، ثم تأكيد صريح و assignment_close_v2 ب revision. لا إنهاء مجموعة أو سحب targets أو حذف نتائج؛ خطأ الإغلاق يفرض قراءة صريحة |

الدليل المتكامل الجديد يستعمل الكاتب 2 والمجموعة نفسها والطالب 4، مع سياسة SYNTHETIC وقبول الذات وطلب العضوية وموافقته عبر RPCs داخل قاعدة واحدة. mixed يشمل MCQ وجزء محاكي قائم؛ full-practical يستعمل المرجع القائم وإصداره. لا seed لمرشح أو publication أو link في الاختبار المتكامل أو --assignments النهائي: تُهيأ حزمة المراجعة الخاصة فقط ثم تنفذ القناة الخادمية. اختبارات sql-assignments-db المنفصلة تحتفظ بعينة تفويض مثبتة مسبقًا، ولا تُقدم كدليل ناشر.

P1 و P2 الافتراضية تبقيان مستقلتين. دليل التكامل هو الاختبار الجديد والحاضنة ذات القاعدة الواحدة؛ لا جمع نجاح حاضنتين أو ادعاء auth/Realtime/PostgREST حي.

## 4. المشترك والصلاحيات و Scale

الدور assess_authoring_bridge هو NOLOGIN/NOINHERIT/NOSUPERUSER/NOBYPASSRLS، بلا عضوية للمستخدم أو العامل. منح EXECUTE محصورة في content_submit_v1 وأربع دوال داخلية: read/candidate/install/bind. لا قراءة عامة للمرشحين أو تثبيت خارج المجموعة والنسخة المأذونتين، ولا كتابة مباشرة للجداول أو المراجعات أو الروابط. لا منح جديدة للعامل، ولا owner أو حسابات أو surveys للمشرف. اختُبر رفض SET ROLE من session authorization محدود، لا منجلسة postgres القادرة إداريًا على تبديل الأدوار.

منفذ PostgreSQL يقبل connection factory وهوية ومجموعة مثبتتين من مضيف موثوق؛ لا ENV/URL أو runtime entrypoint أو هوية من طلب publish. لا LOGIN حي مهيأ. النقل المنتج لاحقًا ملزم بإثبات الجلسة والنطاق. المعاملة READ COMMITTED تمسك scope/profile ثم draft FOR UPDATE، والمراجع وحزمة المراجعة FOR SHARE حتى COMMIT؛ التثبيت والربط يعيدان التحقق داخلها.

صفحات 20/maxSQL100؛ يحتفظ adapter بحد 5 عمليات تجهيز غير محسومة و 20 رمز مراجعة. epoch/AbortSignal وفحص scope قبل/بعد يمنعون الرد المتأخر. انتهاء العرض محسوب من serverNow ناقص زمن النقل وبساعة رتيبة. فقد operation غير محسومة بإعادة التحميل قد يترك review حتى TTL، دون تأكيد تلقائي أو إسناد مكرر. قراءة الإسنادات مصفحة ولا تفترض وجود إيصال بعينه في الصفحة الأولى.

حزمة المراجعة≤128KiB بصيغتي JSONB/text، وواحدة لكل revision ضمن 5 مسودات×100revision؛ قد تضيف حتى 64MiB/كاتب قبل overhead فوق المسودات والمنشورات. لا ضمان FREE؛ الاحتفاظ والتنظيف و restore وقياس السعة والأداء والقفل العام بوابات قبل التشغيل، بلا عامل تنظيف أو رفع حدود هنا.

## 5. الطب والتصحيح

المراجعات موسومة هندسية/SYNTHETIC، ونص الحروف مملوك للاختبار فقط؛ لا اعتماد طبي أو ترخيص مصدر خارجي. الحالات وأجزاء المحاكي القائمة تختبر العقود والإصدارات؛ initialSettings ليست خلفية أو إجابة معتمدة للتشغيل. لا حقائق أو مصادر أو تراخيص أو اعتماد سريري مخترع، ولا فحوص أو صور أو كتابي جديد. لا تغيير مصحح أو درجات أو أوزان أو بوابات حرجة أو إصدار تقييم. O108 والمصادر والرخص والخلفيات و Marker والمراجعات الحقيقية تبقى مطلوبة قبل محتوى فعلي.
