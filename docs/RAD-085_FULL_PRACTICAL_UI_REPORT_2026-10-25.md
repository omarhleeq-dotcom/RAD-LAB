# RAD-085 / P2-UI — متابعة full-practical المحلية

## 1. الانحرافات والميزانية

الهدف الواحد: مسودة full-practical مستقلة من الفحوص والحالات القائمة، ومعاينة آمنة وتجربة إسناد اصطناعي لمجموعات المشرف. الميزانية المعلنة16ملفًا:8ملفات authoring-review قائمة عدا اختبار P2 السابق، [اختبار عملي جديد](../src/features/authoring-review/practical.test.ts)، [سكربت تدقيق P2](../scripts/qa/rad-085-authoring-audit.mjs)، الخطة والحالة وHANDOFF وهذا التقرير ولقطتاEN/AR. صفر وحدات assess مشتركة أو قاعدة بيانات معدلة، ولا توسع ملفات أو إصلاح جانبي. استُكمل checkout نفسه دون worktree أو subagents.

**حد تنفيذي معلن:** المعاينة تعرض PracticalControls القائمة فقط. استيراد PracticalScene فشل حارس browser imports القائم: يجلب ملفات geometry وراديوغراف من مجلدات data/exams وdata/cases. لم تُستثنَ الملفات من الحارس، ولم يُعدّل مكوّن المشهد أو تُنشأ آلية رسم بديلة. تفصح المعاينة EN/AR أن runner الطالب يعرض مشهدًا أيضًا؛ **لا تطابق بصري كامل أو اكتمال قبول المعاينة**. تضمين المشهد يحتاج فصل بيانات الرسم العامة الآمنة بعقد مأذون ومراجعة لاحقة، دون أهداف التقييم أو تخفيف الحارس.

بدأ checkout علىmain برأس31e9cbf ومرجعorigin/mainقديم4118326؛ فشلت أول status:summary في العثور علىRAD-085. تحققت أداةGitHub وdocs:context أن#137 مفتوح وDraft وغير مدموج، برأس807057c وmain31e9cbf. جُلبت المراجع وانتقل checkout نفسه إلى فرعrad-085-plan-2026-10-25. إعدادremoteالمحدود استلزم جلب المرجع صراحة ثم switch --no-track؛ لم تُنشأ نسخة عمل أوPR بديل. استُخدمت مهارة cloud-environment-runtime لفحص البيئة وسياسة الاتصال دون تغييرهما.

## 2. المنجز والمستبعد

- إنشاء full-practical مستقل عنmixed، باسمEnglish وسياسة المدة والمحاولات وإظهار العلامة القائمة. غيابtrackفي مسودةP2القديمة يعنيmixed فقط؛ لا تحويل بين المسارين في الواجهة، والحفظ يرفض تغيير مسار هوية محفوظة.
- إضافة وحذف وترتيب البنود واختيار الفحص/الحالة القائمة، معcaseRef الحالية ونسختها وevaluatorVersion للمؤلف. الكتالوج مشتق من السجل وpublicCaseId، دون IDs ثابتة للفحوص أو المشرفين أو المجموعات. ترفض النسخ القديمة أو غير المدعومة.
- رفض MCQ وsimulator-part داخل full-practical، ورفض practical داخلmixed، حتى عند حفظ مسودة ناقصة. إعادة استخدام جلسة المسودة والحفظ والإسناد والـadapter القائمة، دون مسار نشر أو مخزن موازٍ.
- لا محرر علامات أوrubric أو أوزان أو بوابات جديدة. المصدر والترخيص ونسبة التأليف وملاحظاته مدخلات خالية بدايةً ومنفصلة عن المراجعة المستقلة. لا reviewedBy أو مصدر أو رخصة أو اعتماد طبي مخترع؛ تعبئة QA الاصطناعية ليست دليل ترخيص للحالات.
- معاينة مستقلة لبند واحد، بإسقاط whitelist صريح حتى داخل بيانات العرض المتداخلة. لا مفاتيح أوrubrics أو أهداف تقييم أو حقول مؤلف. تنقل بقيم مؤقتة لكل بند دون IDs مكررة؛ الإغلاق والتبديل وانتهاء الرؤية يمحوها.
- مراجعة إسناد اصطناعي تعرض المجموعة ونسختها واسم المسودة وrevision وعدد المستهدفين وصفحاتهم قبل التأكيد. الحفظ والإسناد موسومان اصطناعيين محليين؛ لا محاولة أو تعريض أو تصحيح أو إرسال أوpublication صالحة للتثبيت.
- التحميل والفراغ والخطأ والإلغاء والتعارض والسحب والانتهاء، وحراسةAbortSignal وهوية الطلب والـmount ضد ردودadapter المتأخرة. لا overwrite أو إعادة إسناد آلية بعد التعارض.

العرض أداةloopback للمراجعة دون route أو قائمة منتج جديدة. P1 وmixed محفوظتان دون إعادة تصميم. لا بيانات أو حسابات أو نتائج حقيقية أو كتابي أو صور أوExcel/paste أو بنك. ملاحظة تكرار تعطيل/حذف الحسابات خارج النطاق ولم تُصلح جانبيًا.
