## 4. الوحدات المشتركة وScale

التغيير المشترك في local-database فقط: خيار محدود `through='f'` للترقية الاصطناعية، و`lineEndings='lf'|'crlf'`؛ الافتراضي latest/LF باقٍ لأدوات الصيانة السابقة. الخيارات غير المعروفة ترفض، ولا URL أو مشروع أو أسرار. PostgreSQL عنقود محلي قابل للإتلاف عبر Unix socket داخل مجلد0700 بلا TCP؛ port يفتح معاملات مستقلة، وقراءات fixture الإدارية تسير بالتتابع عبر اتصالها الواحد.

حدود Scale: حزمة يدوية واحدة لمخطط F المحدد؛ الإضافة الموجودة/الجزئية أو أي drift توقفها. قوائم الجداول/التواقيع/البصمات مقصودة ومحدودة بعقد الإصدار؛ رفعها يحتاج مراجعة إضافة لاحقة، لا توسيع تلقائي أو normalization. الفهارس الحالية ودفعات maintain1..100 وSKIP LOCKED والحذف الذري تبقى كما هي؛ لا قراءة طلاب غير محدودة في حارس المزود، فقط catalogue وحالة gate. أدوات QA تفحص بيانات fixture صناعية في الذاكرة ولا تطبعها؛ الناتج أكواد وأسماء checks وأعلام فقط.

## 7. المتبقي والبوابات

لم يُنفذ الملف على الأصلية من الوكيل ولم يصل صفه النهائي من المالك. لا نسخة أو restore جديدة، ولا دورة استعادة مكتملة. النسخة الشاملة اللاحقة تحتاج جرد تغطيتها: القاعدة والأدوار والبيانات وعلاقات Auth/Storage والكائنات وإعدادات التطبيق/الهوية وتبعياتها؛ dump قاعدة وحده ليس نسخة كل النظام. المفاتيح والملفات خارج Git/المحادثة، ولا تغيير إنتاجي الآن أو مدة مخترعة للمزود.

استعادة snapshot قديمة قد تعيد إسنادًا أغلق أو حسابًا عُطل أو موافقة/metadata حذفت. purge النتائج وحده لا يعيد الحالات الأحدث، وlaunch_gate=false تحجب البدء فقط. يبقى الوصول محجورًا خارج API أثناء restore حتى إعادة الآثار الأحدث والحذف وفحص ACL. دليل إعادة تطبيق مستقل ودورة backup/import/restore لم ينفذا؛ شاهد الخطر السابق لا يكفي لإعلانهما مكتملين.
