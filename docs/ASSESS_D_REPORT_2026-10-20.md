## 2. المنجز والمؤجل

- صفحة Assess للمستخدم المعتمد، وقائمة إسنادات مصفحة بـ20 وkeyset. الخدمة تعيد فحص الاعتماد والمستهدف؛ التخزين والقراءات منفصلة عن Practice. التنقل يظهر في pilot، وتبقى حسابات غير pilot بلا اتصال. لا صفحة «محاولاتي» أو سجل F جديد.
- runner لمسار mixed فقط، single-choice وsimulator-part. محتوى الأسئلة وأدوات الحل إنجليزي، ورسائل المنصة عربية/إنجليزية. لا full-practical أو مسار E.
- MCQ قابلة للتعديل والمسح قبل التسليم؛ حفظ تلقائي بعد600ms أو قبل التنقل/التعريض/التسليم. draft في الذاكرة فقط؛ لا localStorage للأجوبة أو Practice/events/logs أو حساب درجة بالمتصفح. العرض المؤكد يأتي بعد قراءة الخادم. التحميل الجديد يستعيد إجابات الخادم؛ URL يحتفظ بمعرف المحاولة فقط، وتفويضها بالخادم.
- طلب واحد قيد التنفيذ، ومهلة اتصال محلية15ثانية تنقله إلى غير مؤكد دون ادعاء إلغاء المعاملة بالخادم؛ انقطاع/إقرار مفقود يبقي العملية بنفس المعرف والrevision والجسم. المصالحة تقرأ الخادم ثم تعيد نفس الطلب إن بقي active. conflict يوقف التعديل ويستبدل التعديلات المحلية بحالة الخادم عند المصالحة الصريحة؛ لا last-write-wins. التسليم/انتهاء المهلة يمسح تفاصيل الواجهة. توقيت الخادم يثبت القبول؛ مؤقت الواجهة يطلب تحديثًا واحدًا عند المهلة ولا يمنح صلاحية حفظ.
- تعريض واحد ذري عبر command_v1 القائمة؛ قفل SQL يبقى بعد refresh والاستكمال. تنبيه قبل التسليم يعد MCQ الفارغ وكل جزء بلا تعريض غير محلول. لا إعادة ضبط/نتيجة بند/حل أو تلميح readiness.
- أدوات مستقلة عن Practice، تُنشأ فقط من allowlist بعد تحقق Node ومحلل DTO. SID لا يعرض مشهدًا أو kVp أو Marker. اختيار letter لا يحرك markerPosition. لا استيراد محرك/حالة خاصة/إعدادات خلفية كاملة في المتصفح. حدود min/max هي مجال الاختيار، وليست نطاقات الإجابة الصحيحة.
- عناصر المشهد الحالية رسم هندسي بسيط معلن: detector/tube/marker/beam، وليست محاكاة تشريحية جديدة. تُرسل فقط مدخلات العناصر المعلنة، ويُرفض اسم عنصر/أداة غير مدعوم. النص البديل يصف الإعدادات الظاهرة وحدها، بلا معايير أو أهداف. الخلفية المطلوبة لهذا العرض جزء من مراجعة O108 لكل سؤال؛ لا ادعاء أن الرسم يكفي لكل سؤال Marker تشريحي. توسيع العرض يحتاج نطاقًا ودليلًا واختبارًا لاحقًا.
- إدارة دنيا للمالك عبر مستند publication JSON: البنود والمفاتيح الخاصة والخلفية والمعايير والمصادر والوقت والمحاولات والمجموع وعلامات البنود وإصداراتها. كل مرشح immutable؛ تعديل المحتوى بإصدار جديد. metadata فقط في قائمة المالك، ولا قراءة مباشرة للجداول/المستند حتى من حسابه؛ المالك يملك الإدخال الذي يكتبه، لا يُرسل مفتاح عامل للمتصفح.
- content_submit_v1 يحجز metadata غير available ومرشحًا خاصًا. `installMixedContent` منفذ Node موثوق يقرأ المستند الخاص ويطبق validator C مع تحقق عرض D، ثم يثبت publication والإتاحة وحذف نسخة المستند المرحلية ذريًا. لا تثبيت من المتصفح، ولا استدعاء تلقائي أو runtime/مجدول منشور. الإرسال ليس نشرًا؛ لوحة pending صريحة. فشل التحقق يبقي المرشح للمراجعة ولا يجعله قابلًا للإسناد. لا endpoint رفض/تعديل/حذف مرشح في هذه النسخة الدنيا؛ إصدار مصحح مستقل، ومعالجة المرشح المرفوض ضمن تجهيز runtime والاحتفاظ قبل بيانات حقيقية.

## 4. المشترك وScale

القائمة العامة تربط Assess في pilot؛ لوحة المالك تضيف محرر المحتوى بعد فتح القسم. لا تغيير سلوك التدريب أو API الخاصة به. ترجمات جديدة متزامنة؛ العربية المضافة DRAFT آلية للمراجعة البشرية.

C وD أصبحتا requiredMigrations مع check catalogue للواجهة. لا تبقى C خلفية مؤجلة بعد استعمال start/command من المتصفح. pins الجديدة تعكس مراجعة طبقات الاتصال الفعلية؛ لا تعديل PILOT_SCHEMA_VERIFIED أو Actions Variable أو workflow أو تجاوز الحارس. قائمة serverModules مستقلة تحظر استيراد C/D الخاصة حتى بعد ترقية SQL. اختبارات B السابقة تعمل على fixture مستقلة محفوظة، مع ثبات التوقعات؛ اختبارات D تثبت رفض إثبات B القديم.

السقوف: صفحة واجهة20/خادم100، مرشح≤2MB،≤20مرشحًا pending لكل مالك (قفل صف هوية المالك يسلسل العد)، والبنود/الخيارات/الأوامر والمحاولات وفق حدود C. القوائم ليست قراءة غير محدودة. مرجع assessment UUID مملوك لمنشئه؛ versions لا تسمح takeover من مالك آخر. القفل advisory على assessment يسلسل versions. لا وعد سعة/QPS أو Free؛ قياس وتجهيز عامل اعتماد المحتوى ورفضه/تنظيفه مطلوبان قبل حمل حقيقي. vocabulary العرض محدود صراحةً ويرفض الإضافات؛ الرفع بإضافة renderer/validation ومراجعة الخلفية دون تغيير بيانات التدريب.

- بناء `build:pages` ناجح بإعداد Supabase اصطناعي محلي فقط، دون attestation إنتاج أو اتصال مزود. فحص static chunks لم يجد correctOptionId/fixedSettings/gradePublication/installMixedContent أو RPC العامل الخاص. تدقيق D:316تحققًا و20حالة axe/overflow؛ تدقيق المالك القائم:676تحققًا و16حالة، جميعها EN/AR390/1440. تشمل lost exposure ack/replay نفسه، refresh lock، SID بلا مشهد أو kVp، Marker بلا تحريك تلقائي، conflict منقح، تنبيه غير المحلول وتسليم يمسح التفاصيل، وpending content الصريح. حُفظت لقطات محلية خارج Git وفُحص عرض العربية/LTR و390/1440؛ ليست صورة/فحصًا جديدًا في المنتج.
