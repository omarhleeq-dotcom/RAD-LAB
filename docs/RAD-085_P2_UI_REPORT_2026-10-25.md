# RAD-085 / P2-UI — تأليف ومعاينة وإسناد اصطناعي محلي

## 1. الانحرافات والميزانية

الهدف الواحد المأذون: واجهة محلية لتأليف مسودة MCQ وأجزاء المحاكي، ومعاينة الطالب وتجربة إسنادها إلى مجموعات المشرف ببيانات اصطناعية فقط. الميزانية المعلنة قبل التحرير16ملفًا بالضبط:9ملفات جديدة في authoring-review، سكربت تدقيق، الخطة والحالة وHANDOFF وهذا التقرير، ولقطتا EN/AR. صفر وحدات مشتركة قائمة معدّلة؛ ملفات P1-UI وواجهات المنتج والربط الحي لم تتغير. لا توسع خارج الميزانية أو worktree أو subagents.

تحقق موصل GitHub من أن [PR #137](https://github.com/omarhleeq-dotcom/RAD-LAB/pull/137) مفتوح وDraft وغير مدموج، وأكد main عند `31e9cbfba6574a9e87b59d47a687f99864c74b21` ورأس PR عند `1f57b0da9e1e69dccf68d388aec7685c74251865` قبل العمل. كانت البداية على checkout main دون ملفات RAD-085؛ فشل status:summary أولًا برسالة unknown task، ثم جُلب مرجع الفرع الصريح واستُكمل fast-forward في checkout نفسه. نجح docs:context وstatus:summary لـRAD-085 بعد ذلك، وقُرئت المهام المرتبطة بـAssess. لا استنتاج للنشر من مراجع Git.

تُجمع كل SQL واختبارات قاعدة البيانات الجديدة في جلسة أخيرة واحدة بعد تجهيز الواجهات؛ لا تعديل أو تطبيق قاعدة أو RPC أو RLS أو checks هنا. لا Supabase/variables/PILOT_SCHEMA_VERIFIED/launch_gate/CONSENT_VERSION أو عامل أو hosted preview أو نشر. PR نفسه يبقى Draft دون ready/merge/auto-merge.

## 2. المنجز والمستبعد

- إنشاء مسودة محلية وتسميتها بالإنجليزية وسياسة مدة بالثواني الصحيحة أو دون توقيت، وحد محاولات وسياسة hidden/after-submission القائمة. حفظ المسودة غير المكتملة ممكن في الذاكرة الاصطناعية؛ المعاينة والإسناد يتطلبان تحقق الحقول.
- إضافة MCQ وخياراته وتعديلها وحذفها، واختيار مفتاح واحد فقط، وحذف البنود وترتيبها ونقاط عشرية دقيقة. حقول المؤلف والمصدر وملاحظات الترخيص والملاحظات الخاصة منفصلة عن أي مراجعة مستقلة؛ لا reviewedBy أو اعتماد أو مصدر/رخصة افتراضيان.
- إضافة simulator-part من مراجع الحالات والقواعد القائمة فقط. الكتالوج مشتق من CASES وruleParts وsettingsSpec وcaseVersion؛ يقتصر العرض المحلي على الأجزاء العددية المستقلة من range/equals، بلا Marker أو معيار شرطي أو full-practical. لا تعديل للحالات أو النقاط أو الإصدارات أو قواعد التقييم. الأدوات الابتدائية من الحالة نفسها للمراجعة الهندسية، وليست خلفية معتمدة أو إجابة نموذجية.
- أخطاء موجهة لمسار الحقل ورقم البند، وإجمالي النقاط بالدوال الكسرية القائمة. لا مصحح أو محرك درجات جديد، ولا نتائج طلاب أو تصحيح أثناء المعاينة.
- معاينة مستقلة تعرض بندًا واحدًا في كل مرة مع التنقل وحفظ الاختيارات المؤقتة بينها، وتستقبل whitelist للطالب فقط؛ التأليف يُزال من شجرة العرض خلالها. مفاتيح MCQ وحقول المؤلف والمصدر والرخصة وrubric والنقاط الخاصة لا تصل إلى مكوّن المعاينة. الخيارات والمدخلات مؤقتة وتمحى عند الإغلاق، بلا محاولة أو تعريض أو حفظ أو إرسال.
- مراجعة إسناد اصطناعي للمجموعة المحددة التابعة للمشرف فقط: اسم المسودة ونسختها، المجموعة ونسختها، عدد المستهدفين وصفحاتهم، وحد انتهاء المراجعة؛ تأكيد منفصل أو إلغاء. الإيصال اصطناعي محلي فقط، ولا ينشئ إسناد خدمة أو publication أو نسخة محتوى قابلة للتثبيت.
- حالات مسودة فارغة وتحميل وخطأ وإلغاء وتعارض وفقد التعيين وانتهاء المجموعة. التبديل يعيد تركيب جلسة بالنطاق، والإلغاء يوقف العرض، وكل await محروس أيضًا من adapter لا يحترم AbortSignal. مؤقت الرؤية يمحو المسودة والمعاينة والمستهدفين دون نقرة ويجزئ الفترات الطويلة وفق سقف مؤقت المتصفح. لا إعادة محاولة كتابة/إسناد تلقائية بعد التعارض.

الواجهة محلية منفصلة عن routes والقوائم وحسابات الخدمة. لا كتابي أو صور أو استيراد Excel/paste أو بنك حقيقي أو تأليف full-practical أو نشر/worker في هذه الدفعة. أمثلة MCQ في الاختبارات والتدقيق حروف وتوكنات غير سريرية؛ لا أسئلة طبية مخترعة.
