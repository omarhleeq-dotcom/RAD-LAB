الـadapter لا ينشئ Supabase client أو قاعدة/جداول/مجموعات/صلاحيات ثانية. خادم القبول HTTP على127.0.0.1 فقط، بحسابات اصطناعية ثابتة للسيناريو، ومحدد RPC محدود وHost/Origin وCSP، وPostgreSQL عبر Unix socket بلا TCP أو URL موروث. تهيئة السياسة والقبول اصطناعية داخل إعداد الاختبار فقط، وتستعمل RPC الذات للحسابات الاصطناعية. --unconfigured يبقي السياسة فارغة ونموذج الانضمام مغلقًا. لا اتصال حي أو اعتماد مشاركة حقيقية.

لم تُعدل الترحيلات الثلاثة أو بصماتها أو الحراس أو شهادات التطبيق؛ لم يكشف الربط عيب SQL يوجب إصلاحًا ضمن هذه الدفعة. P2 وpublication bridge والعامل والجدولة والكتابي والصور خارج العمل. تقارير الواجهات وSQL السابقة محفوظة تاريخيًا، ولا تدعي هذه الدفعة تشغيلها حيًا أو قبولها من المالك.

## 4. المشترك وScale وحدود الإبطال

عقد P1 أضاف total الاختياري واشتراك إبطال اختياري وحالة تعيين غير معروفة وإيصال رمز مرتبط بمجموعة. الواجهات الاصطناعية السابقة تبقى للاختبارات التاريخية؛ خدمة SQL تستعمل الواجهة نفسها، دون route أو قائمة منتج أو ربط pilot حي. لا تعديل بيانات فحص أو مصحح أو رسم.

القراءة المركبة حتى6RPCs قصيرة منفصلة،20صفًا لكل قائمة وUUID keyset من الخادم؛ لا جلب كل الأعضاء أو النتائج/التعيينات. تحقق إضافي محدود لمجموعة إيصال الرمز يمنع فقدانه عند وجودها خارج أول20مجموعة دون مسح الصفحات. زر الرجوع لقائمة المجموعات متاح عند رفض المجموعة المختارة، دون إبقاء بياناتها. يُعاد التحقق من جيل المجموعة بعد تركيب صفحاتها، ولا تتحول RPCs المنفصلة إلى معاملة ذرية مخترعة. الطالب لا يستنتج عضوية من القرار التاريخي؛ isMember=null في عقد SQL بدل ادعاء عضوية أو نفيها. معرفات الأعضاء ظاهرة بجانب أسمائهم لربطهم بسجلات التدريب عند تكرار الأسماء. التعيين/إنشاء المجموعة يعاد تفويضهما في SQL، دون كشف directory للمشرف.

إشعارات SSE داخل الخادم المحلي فقط، بلا بيانات أشخاص وبجيل متزايد؛ تبدأ القراءات بعد تثبيت جيل القناة كي لا تضيع إشارة في فجوة الاشتراك؛ الاستجابة تحمل جيل وقت بدء القراءة، ويُتجاهل إشعار أقدم من استجابة مكتملة، بينما يظل الجيل الأحدث مبطلًا. فقد القناة يمسح العرض؛ لا polling أو إعادة تحميل أو retry تلقائي. وقت العرض مبني على serverNow وperformance.now مع خصم زمن النقل؛ لا ساعة العميل لتوسيع نافذة SQL. عند ACK مفقود لا تعاد mutation تلقائيًا؛ التحديث ثم قرار إعادة صريح، والتكرار/التعارض بحسب عقد RPC القائم.

هذا لا يثبت وصول إبطال لتعديل إداري خارج القناة المحلية، ولا PostgREST/auth/Realtime أو انقطاع مزود حي. قبل أي تشغيل يلزم توصيل واختبار النقل والإشعارات الفعلية وإدارة الجلسة والموافقة المعتمدة بإذن مستقل. سقف20صفًا/max100 في SQL و1000عضو والقفل العالمي والسعة/انتظار القفل والتخزين/الاحتفاظ كما في العقود؛ لم تقَس120جلسة أوFREE ولا ميزانية إنتاج. IDs وأسماء الحسابات ثابتة في حاضنة الاختبار الاصطناعية وحدها، وليست قائمة حسابات منتج.
