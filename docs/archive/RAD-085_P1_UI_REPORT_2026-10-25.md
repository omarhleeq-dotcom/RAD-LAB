- تعيين وسحب المشرف عبر المالك مع تأكيد السحب، ومشرفان ومجموعات من البيانات.

- تحميل/فراغ/خطأ/تعارض/انتهاء/سحب تعيين، ومسح العرض والرمز عند تبديل الحساب أو المجموعة أو سيناريو الرؤية، وإلغاء الاستجابات المتأخرة. مؤقت أقرب حد للرؤية يخفي النتائج دون نقرة؛ تبقى رسالة انتهاء المجموعة بلا بيانات الطلاب. تُجزأ المدد الطويلة إلى مؤقتات ضمن حد المتصفح، دون إخفاء مبكر لمجموعة تنتهي بعد أكثر من24يومًا. صُححت أثناء التحقق حالة كانت تخفي رسالة الانتهاء مع البيانات، وحالة تجاوز حد مؤقت المتصفح؛ أضيف اختبار رجعي للمدد الطويلة.
- نص موافقة EN/AR مقترح داخل تفاصيل للمراجعة فقط، دون زر قبول أو حفظ أو رفع الإصدار؛ surveys واعتماد/حذف حسابات الموقع غير معروضة للمشرف.

العرض مستقل عن مسارات التطبيق وقوائمه والربط الحي؛ لا يعرض كميزة عاملة للمستخدم. لا محرر أسئلة أو كتابي أو صور أو تعديل محرك/درجات. أرقام النتائج fixtures غير طبية ولا يعاد تقييمها.

## 4. المشترك وScale وعقد الربط اللاحق

[contracts](../../src/features/supervisor-review/contracts.ts) يعرفDTO وعملياتReviewAdapter؛ [العرض](../../src/features/supervisor-review/SupervisorReview.tsx) يستقبل بيانات وcallbacks فقط؛ [الحاوية](../../src/features/supervisor-review/ReviewSession.tsx) تدير الإلغاء والتبديل والرؤية؛ [synthetic](../../src/features/supervisor-review/synthetic.ts) محلي في الذاكرة بلاstorage/network/pilot auth. لا ملف مشترك قائم تغير، ولاIDs مشرفين/مجموعات ثابتة في العرض أو العقد؛ IDs مولدة فيfixture فقط. قائمة حسابات المراجعة محلية وليستdirectory منتج.

سقفfixture: مشرفان و24طالبًا لتمرين الصفحة الثانية، بلا ادعاء سعة إنتاج. حجم صفحة20 دون خيارتحميل الجميع. cursor محليoffset نصي للعرض فقط؛ الربط الحقيقي يحتاجcursor خادميًا معتمًا ومقيدًا بالهوية والنطاق والمرشح، وترشيح الصلاحيات قبلcount/aggregate/paging. صفحات fixture المادية تحفظ كلها في ذاكرة مولّد البيانات الاصطناعية فقط؛ لا يُنقل ذلك إلى عميل الخدمة الحقيقي. مخططv1 المقترح يحصر الأدوار والحالات بهذه الدفعة؛ تمديده يحتاج عقدًا وإصدارًا مقصودًا. لاschema أو أسماءRPC نهائية من أسماءDTO/operations.
