## 2. المنجز والمستبعد وخيارات الهوية

اختير أبسط تركيب فوق منفذ الجسر القائم: LOGIN خدمة مخصص NOINHERIT، عضويته الوحيدة المقررة assess_authoring_bridge مع SET=true وINHERIT=false وADMIN=false، ومضيف موثوق يثبت جلسة المستخدم والمجموعة ويعيد تحققها. لا اتصال خدمة بصلاحية owner/service_role، ولا ناشر آخر، ولا LOGIN لكل مشرف. إعداد الدور موجود **داخل fixture الصناعية فقط**؛ لا ملف تهيئة تشغيلية ولا هوية حية أو سر منشأ. المصادقة المحلية عبر Unix socket وtrust داخل دليل0700؛ لذلك لا دليل مصادقة كلمة مرور أو TLS.

## 4. الإبطال والتعافي والمشترك وScale

- يعيد المضيف التحقق قبل اكتساب الاتصال، وبعده، وبعد قراءة SQL التي قد تنتظر قفلًا، وقبل/بعد كل قدرة كتابة، وقبل COMMIT وبعده وعند تسليم النتيجة بعد تنظيف الاتصال. أي تبدل subject/group أو انتهاء الجلسة أو رفض المصادقة يبطل capability نهائيًا. مؤقت انتهاء الجلسة يقطع أيضًا طلبًا محجوبًا فيSQL دون طلب جديد أو polling. التمديد لا يطيل صلاحية capability الأصلية؛ يلزم فتح جلسة جديدة.
- revoke يبطل الجلسات الحالية المطابقة ويشعر مشتركيها ويغلق الاتصال النشط. مصدر المصادقة الموثوق يجب أن يسجل السحب أيضًا لمنع فتح جلسة جديدة؛ الحدث وحده ليس سجل إبطال دائمًا. close إلغاء محلي نهائي للجلسة؛ disconnect فقد القناة، يبطل كل الجلسات ويغلق pool الخاص ويمنع إعادة فتحها في المضيف نفسه. التعافي يتطلب مضيفًا جديدًا ومصادقة حديثة بعد استعادة القناة. المشترك اللاحق بجلسة ميتة يتلقى الإبطال فورًا.
- NOLOGIN يمنع الاتصال الجديد فقط؛ الاتصال المفتوح يواصل SELECT. سحب عضوية SET يُفحص عند checkout، ولا يوصف بأنه قطع فوري لاتصال يعمل بالفعل. الإجراء التشغيلي اللاحق لسحب هوية الخدمة: إغلاق النقل والمضيف/pool، منع LOGIN وتدوير الهوية، وإنهاء sessions الموثقة لدى PostgreSQL/pooler عبر مسؤول مأذون، ثم فحص عدم إمكان الاتصال/إعادة الاستخدام. لم ينفذ إجراء تشغيل حي هنا.
- pool محلي من مكتبة pg بحجم1 في الاختبارات لإثبات إعادة الاستخدام: ROLLBACK ثم DISCARD ALL قبل وبعد الإعارة، والتحويل إلى الدور/claim بـLOCAL فقط. الإبطال أو تعذر التنظيف يدمر الاتصال. لا إعادة تلقائية لعملية كتابة عند الانقطاع أو إعادة الاتصال. لا إثبات multiplexing أو reset/cancel لمزوّد pooler.
- SQL وأقفال scope/profile تحددان ترتيب الإدارة والطلب. سحب التعيين الملتزم قبل انتظار الطلب يرفضه؛ التغيير الذي ينتظر قفل الطلب قد يلتزم بعده. انتهاء الوقت يُعاد بعد الانتظار. حدث إبطال موصّل يقطع الطلب أثناء الانتظار أو التنفيذ؛ حدث بعد COMMIT يحجب الرد لكنه **لا يلغي كتابة ملتزمة**. لا ضمان إبطال فوري لتغيير إداري خارج القناة.
- سحب مشاركة الطالب يؤثر على لقطة المستهدفين والتأكيد والنتائج؛ لا يجعل نشر محتوى الكاتب غير قانوني تلقائيًا. سحب قبل اكتساب قفل التأكيد يرفض لقطة قديمة دون assignment. إن سبق التأكيد السحب وفق القفل فقد يبقى الإسناد/targets المثبتان كما تنص العقود؛ لا سحب نشر أو تعديل targets تلقائي.
- فقد ACK قبل إرسال COMMIT يرجع الكتابات؛ فقده بعد COMMIT يتركها. كلاهما خطأ مجهول للمستدعي، بلا إعادة نشر أو إسناد آلية. receipt قراءة مفوضة تنتهي ROLLBACK؛ المصالحة تكرر القراءة فقط. إذا سُحبت الصلاحية لا تُكشف الإيصالات حتى تفويض جديد. المصالحة والإسناد القائمان أُعيد اختبارهما دون API نشر جديد.

Scale: سقف الجلسات النشطة32 لكل مضيف قابل للضبط، مع رفض تجاوز السقف وتحرير السجل عند الإبطال/الإغلاق. لا cache لقرارات التفويض، ولا polling أو retries؛ عمليات تحقق متعددة تزيد كلفة المصدر الموثوق ويجب قياسها قبل الوصل الحقيقي. pool الحقن يحدد الحجم/المهلات؛ الاختبار يستخدم اتصالًا واحدًا، لا دليل120مستخدمًا أو FREE. صفحات20/max100 وسقوف المسودات/المراجعات القائمة ثابتة. لا تخزين دائم جديد لبيانات المستخدم أو credentials.

## 7. الاحتفاظ والمحو والبنود المفتوحة

حذف الروابط والمراجعات ما زال **عائقًا تشغيليًا مفتوحًا**؛ إبطال الجلسة ومسح المتصفح لا يمحوان authoring_publication_links أو packages أو revisions أو إيصالات الإسناد/نسخ القاعدة. restore قد يعيد الأدوار والعضويات والموافقات القديمة: يبقى النقل محجورًا، ويعاد تطبيق سجل السحب/الحذف الأحدث من اللقطة، ويُنشأ مضيف/pool جديدان؛ لا استعادة cache أو capability أو credential من نسخة قديمة. لا يثبت هذا الاختبار replay سجل سحب تشغيلي أو مزوّد restore.

توصية محددة للمالك: اعتماد مسؤول وإجراء واحد يقرر ترتيب فك ارتباط الروابط/المراجعات مع الإيصالات والحسابات والنسخ، وما يبقى tombstone للتدقيق وكيف يمنع restore إحياء المحذوف. يلزم قبل تشغيل فعلي؛ لا CASCADE شامل أو مدة جديدة أو إجراء حذف تشغيلي نُفذ هنا.
