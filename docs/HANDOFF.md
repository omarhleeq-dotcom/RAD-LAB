# التسليم الحالي — RAD-072 الجزء 2a (تجربة اليد): المرحلة A منجزة، تنتظر مراجعة المالك للتراكبات

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم شغّل `npm run docs:context` (مع `-- --pr NUMBER` لـPR المسودة للجزء 2a) و`npm run status:summary -- --id RAD-072`. [project-status](project-status.md) مصدر الحالة الوحيد. استمر في الـcheckout نفسه، بلا worktree أو subagents. PR مسودة فقط؛ لا ready أو merge أو auto-merge، ولا اشتراك أو polling، ولا فتح أو مشاركة معاينة مستضافة.

## ملخص الحالة
- **الاتجاه الحالي:** RAD-072 قيد التنفيذ. الجزء 1 (الصدر) مدموج في #113. الجزء 2 مقسوم: **2a** تجربة اليد (رسم من حدود مستخلصة من الصورتين المرجعيتين، [القرار](DECISIONS.md#rad072-2a-hand-owner-2026-10-23))، ثم 2b القدم والكاحل، ثم 2c الكتف؛ ثم الجزء 3 (بنود R وصور النتيجة).
- **ينتظر المالك:** مراجعة صور التراكب الثماني وفق [تقرير المرحلة A §8](RAD-072_PART2A_PHASE_A_REPORT_2026-10-23.md#8-قائمة-المالك-والخطوة-التالية): «موافق» أو قائمة تصحيحات.
- **ينتظر مراجِعًا:** لا جديد؛ هوية الكثافتين المستديرتين عند MCP الإبهام غير مراجعة.
- **مرجع Git:** الفرع والقاعدة وPR عبر docs:context؛ التحقق المُشغّل وغير المُشغّل في [تقرير المرحلة A §6](RAD-072_PART2A_PHASE_A_REPORT_2026-10-23.md#6-التحقق).
- **مخاطر معلنة:** المخططات توضيحية للرسم فقط، ليست قياسًا. `hand-model.ts` مشترك ولا يتغير. استثناء scene-dom في المرحلة B فقط ولمفاتيح hand-pa وhand-lateral في `hand-hashes.json` وحدها.

## المنجز في المرحلة A
- `scripts/trace-outlines/trace-hand-outlines.py` (+README): بذور منسقة + كشف حواف + تبسيط؛ حتمي ودون اتصال؛ `--check` يثبت تطابق JSON بايتًا ببايت، و`--overlays` يعيد الصور.
- `src/features/positioning/hand-outlines.json`: 44 بنية PA و14 جانبية، بإحداثيات px الصورة نفسها؛ لكل بنية `follows` لأنبوب نموذج اليد. غير مستورد بعد.
- `docs/review/rad-072-hand/`: ثماني صور تراكب، مسجلة `ART-RAD072-HAND-TRACE` في [الأصول](ASSET_PROVENANCE_AND_LICENSES.md).
- **H1 مُشخّص:** في الجانبي عند −10°…−15° تختفي سلاميتا الإبهام (والمشط الأول تقريبًا) تحت عمود الأصابع، لأن الرسم يملأ العظام بتعبئة معتمة من الأبعد إلى الأقرب؛ النموذج سليم. التفاصيل في التقرير §3.

## الخطوة التالية والعوائق
- **بعد موافقة المالك فقط:** المرحلة B على PR نفسه: إعادة رسم منظري الكاشف من المخططات عبر دوال دوران نموذج اليد؛ أسلوب الطبقات للأطراف بتوسيع رموز `scene-style.ts` (فقرة أطراف في ENGINE_GUIDE إن لزم)؛ إصلاح H1 (حدود العظام فوق التعبئات) مع اختبار على كامل مدى الدوران للفحصين؛ مواءمة نسب `HandSideView.tsx` دون هندسة أو تقييم؛ عكس الرسم لحالة يد يمنى مع تعليق، ولا عكس في RTL.
- تحقق المرحلة B: الاختبارات ذات الصلة ثم check/build مرة؛ hand-audit ومتصفح EN/AR 390/1440 وaxe؛ تداخل التسميات؛ إثبات عدم تغير `hand-model.ts` وصور النتيجة والتوصيف وgolden، وأن مفاتيح hand-pa/hand-lateral وحدها تغيرت (مع سبب كل مفتاح)، وبصمات الرسغ والمرفق والطرف السفلي مطابقة.
- ملاحظة خارج النطاق: صورة النتيجة الجانبية لا تحرّك الإبهام؛ أي تغيير لها للجزء 3 وبقرار المالك.
- إذا تعارض الرسم الصحيح مع منطقة مقيمة، توقف وارفع مقترحًا.
