# التسليم الحالي — هوية المقارنة وتجهيز التصفير

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context -- --pr 88` و`npm run status:summary -- --id RAD-058`. الأدلة في المهمة ووصف المسودة فقط؛ [العقد](PILOT_SUPABASE_SETUP.md#practice-comparison-version) و[إجراء التجهيز](PILOT_SUPABASE_SETUP.md#practice-optional-reset).

## المتبقي
الخطوة التالية [فحص الخدمة الجديد](PILOT_SUPABASE_SETUP.md#comparison-owner-service-check) من Console الموقع الحالي على الحاسوب: المالك ثم المشارك، وسطران منقحان بعقد المقارنة وpair متطابق. وردت إفادة تطبيق ترحيل المقارنة من المالك؛ دليلها وحدود فحوص المعاملة في RAD-058 ووصف المسودة. لا تعِد ترحيل المقارنة أو ترحيل التدريب والاسم السابق، ولا تطلب إعادة فحوص SQL التي استوفاها الملف المحروس دون تغير ذي صلة.

بعد نجاح الخدمة للنطاقات الجديدة فقط يُولّد ويسجّل إثبات مطابق وفق [إجراء النشر](PILOT_SUPABASE_SETUP.md#training-deployment-check)، ثم إعادة نشر التحديث المقصود وفحص محاولتين جديدتين ودرجتيهما الفعليتين والرسم والهاتف من المالك. هوية فارغة في صف تاريخي تثبت إتاحة الحقل فقط، لا كتابة جديدة أو نجاح الرسم. أدلة الخدمة والرسم والهاتف السابقة محفوظة بحدودها، ولا تعاد دون تغيير ذي صلة. يلزم استكمال مراجعة المسودة والتحقق من CI للتحديث المقصود دون متابعة دورية؛ استثناءات الحارسين الأولين والثالث معتمدة بحدودها في [القرار](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط).

اختار المالك جميع محاولات Practice للمعاينة فقط؛ لا حذف معتمد. يشغل المسؤول فحص catalogue والعدّ والمعاينة محليًا على المشروع المطابق، ويحفظ المخرجات التفصيلية والنسخة خارج Git والمحادثة. يلزم عدّ المحاولات وfeedback والأحداث، ونسخة مجرّبة الاستعادة ومنع كتابة فعلي للنسخ القديمة قبل تجهيز واعتماد حذف محدد. لا SQL حذف قبل catalogue الحي، ولا درجات افتراضية لاختبار النظافة.

## الحدود والعوائق
لا اتصال إداري أو بيانات اعتماد مهيأة للوكيل؛ لا عدّ أو نسخة حية منفذة. الحسابات والأسماء والأدوار والموافقات محفوظة، والأحداث مقترح إبقاؤها بعد مراجعة أثرها. نجاح المسودة لا يحدّث main أو الروابط القديمة؛ التنظيف ليس علاج الرسم ولا شرط حفظ التاريخ.

حارس النشر يبقى فعالًا ويحجب إثبات SQL القديم بعد تغيره؛ لا تسجيل إثبات أو نشر main أو تغيير سياسات إنتاج تلقائي. الهاتف الفعلي للمالك؛ لا فتح أو مشاركة معاينة مستضافة من الوكيل.

## المتابعة
RAD-058 تبقى review مع وصفها ودليلها وجهة انتظارها معًا. Assess والمشرف وO106–O108 والفحوص والصور مؤجلة. التسليم Draft فقط؛ حقائق Git وCI تُقرأ بأدواتها ولا تنسخ هنا. لا مهمة جديدة أو إعادة اعتماد تصميم التدريب.
