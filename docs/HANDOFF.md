# التسليم الحالي — RAD-085 / اختيار المشرف من دليل المالك

اقرأ [AGENTS](../AGENTS.md)، ثم docs:context وstatus:summary -- --id RAD-085. [project-status](project-status.md) مصدر الحالة الوحيد. استمر في checkout نفسه دون worktree/subagents.

## ملخص الحالة
- **الاتجاه الحالي:** P1 حي بإفادة المالك؛ الاختيار بالبحث والترقيم والتأكيد يحل محل إدخال UUID. [تقرير الدفعة](RAD-085_OWNER_PICKER_REPORT_2026-10-28.md) يحفظ النطاق وpins ودليل QA وحدوده؛ [تقرير DB day](RAD-085_DB_DAY_COMPLETED_2026-10-28.md) يحفظ الأدلة التشغيلية السابقة.
- **ينتظر المالك:** مراجعة الواجهة ثم هاتف P1 بحسابَي اختبار: البحث بالاسم والبريد، التأكيد والإلغاء والتعيين والإبطال. تأكيد حذف النسخ وإفراغ المهملات؛ لا إعادة ترحيل.
- **ينتظر مراجِعًا:** القراءة المحدودة وحالات الرفض، وأدلة DB day والأمن/ACL والحقوق والمزوّد والقبول وخصوصية Auth بلا FK. الجرد لا يغلق بند الخصوصية.
- **مرجع Git:** docs:context لحالة الفرع وDraft PR؛ وصف PR والتقرير لدليل QA/CI؛ لا استنتاج نشر أو فحص هاتف من الدمج.
- **مخاطر معلنة:** الدليل لا يعرض Terms؛ الخادم يحسم الأهلية. كل صفحة ≤20 حسابًا مع ≤20 قراءة تعيين لسجل واحد. launch_gate مغلق والتراجع لم يُشغّل وفق الدليل السابق؛ RAD-082 وRAD-059 قبل أول امتحان حقيقي.

## الخطوة التالية والعوائق
commit التسليم يمنع workflows بـ`[skip ci]` لأن فتح Draft يشغّل Deploy Pages؛ لا CI بعيد لهذه الدفعة، ولا يُزال هذا المنع دون إذن يسمح بالنشر الآلي.

مراجعة المالك للهاتف لازمة للقبول الحقيقي؛ تدقيق المتصفح محلي معزول وبهوية اصطناعية، وليس جلسة Supabase حية. [S7](RAD-085_REMAINING_OPERATIONS_2026-10-26.md#s7-supervisor-restore) مستمر: استعادة الحساب لا تعيد تعيين المشرف أو مجموعاته. مولّد نقل الهاتف وcompanion التراجع مقترحان غير منفذين؛ [قاعدة الهاتف](DECISIONS.md#rad085-mobile-sql-owner-2026-10-28) لأي SQL حي مستقبلي، وسقفها يُرفع بمسار اللابتوب/CLI في RAD-082.

برومبت المتابعة: «اقرأ AGENTS وHANDOFF وتقرير اختيار المشرف؛ تحقق من Draft وCI مباشرة دون polling. راجع نتيجة هاتف P1 بحسابَي اختبار. حافظ على marker وSQL/readiness؛ لا SQL حي أو Variables أو نشر أو ready/merge. أي تعديل جديد: ميزانية مسماة واختبارات السلوك ثم QA المناسب. لا بيانات أشخاص في الملفات».

Draft فقط؛ لا ready/merge/auto-merge، ولا SQL/Supabase حي أو Variables أو نشر عامل أو أسرار أو فتح/مشاركة hosted preview أو subscribe/poll. لا qa:golden أو qa:characterise. لا تغيير لدرجات/مشاهد/بيانات فحوص أو بايتات ترحيل مطبق أو digests الجاهزية.
