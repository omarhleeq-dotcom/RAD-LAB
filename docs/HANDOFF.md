## المتابعة

بروفة Docker worker الحالية نجحت محليًا بعد فحص السعة والتنظيف؛ راجع تقرير P8 للفحوص وحدودها. لا تعديل للبروفة أو CI، ولا إثبات تشغيل حي.

P8 تستكمل D3 لكل مخازن v2 وحقوق/نقل holds والتصفير الانتقائي، وmaintain/recover/health v2 وD4. الاسترداد للمالك المخول فقط، لا active ولا فقد جواب أو إعادة آلي ناجح أو فتح نهائي. الإنذار لا يسجل إرسالًا قبل ACK القناة؛ يوم7 يحذف المؤقت بلا تمديد. المنح النهائية داخل M08 المؤجلة فقط، والجاهزية الجديدة غير مطلوبة حتى P10. لا UI أو job أو قناة موصولة.

المتابعة P9 فقط وفق الخطة وdocs:context: دليل CLI للابتوب ليوم قاعدة واحد بعد RAD-086 والنسخة المحلية الكاملة المتحقق منها؛ preflight/apply/fail/rollback ومقارنة catalogue والبيانات والجاهزية، بقائمة≤16ملفًا معلنة. تبقى M01–M08 deferred وrequired/checks وبايتاتها والـmarker ثابتة، RAD062_AVAILABLE=false وP1_AVAILABLE=true؛ الشواهد التاريخية تستبعد المؤجل بالآلية القائمة. لا SQL حي أو إعادة M1–M4/B أو المُهيّئ أو فتح gate/العامل، ولا تغيير للمحاكي/الدرجات/goldens. حزمتا الطوارئ ثابتتان وطوارئ v2 وdry-run هاتفية وحاجبة. Draft فقط بلا ready/merge/auto-merge أو skip ci أو نشر إضافي أو معاينة مستضافة أو polling.
