## الخطوة التالية والعوائق (نقطة حفظ المرحلة B، غير مُتحقَّق منها)
- **المنجز في B (كود واختبارات وبصمات):** رسم الرسغ PA/الجانبي، والقدم DP/المائل (عظام صلبة لإصلاح البند 13)، طبقات مشتركة `outline-layers.tsx`/`outline-geometry.ts`، المناظر الجانبية للرسغ، إصلاح النسيج الرخو الأيمن في PA، بصمات ثلاثة ملفات وقائمتها، فقرة ENGINE_GUIDE.

- **أعطال معروفة:** لا فشل اختبار أو خطأ أنواع معروف. **روابط ميتة:** `RAD-072_PART2B_PHASE_B_REPORT_2026-10-23.md` غير مكتوب بعد وتشير إليه قائمة البصمات والأصول، فسيفشل `docs:check` حتى يُكتب.
- **الخطوة التالية:** (1) `npm run docs:context`؛ (2) إعادة `npx vitest run src/features/positioning` ثم `npm run check` مرة واحدة والبناء؛ (3) إثبات أن `git diff origin/main` فارغ على النماذج الثلاثة وradiograph وdata وcharacterisation وgolden، وأن مفاتيح scene في ملفات الرسغ والقدم وحدها تغيّرت؛ (4) `simulator-layout-audit.mjs` للفحوص الأربعة وقياس تداخل التسميات؛ (5) كتابة تقرير B بالعربية (S-STD-1 + §8 قائمة هاتف EN/AR) وتحديث project-status؛ (6) `docs:check` و`status:check`.
- **حدود معروفة:** التواء عظام صورة النتيجة للقدم (بند 13) خارج 2b (يلزم تغيير نموذج أو خط أنابيب)؛ حدّا اليد المقبولان؛ فرق نسبة الزند مع اليد تقرير فقط.
