# التسليم الحالي — التدريب ومتابعة المتدربين

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context` و`npm run status:summary -- --id RAD-058`. [S-MY-ATTEMPTS-1](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط) يتضمن تعديل المالك المعتمد: ملخص الرئيسية، تدريب مجمّع، متابعة مستقلة للمتدربين، والاسم في الحساب. لا إعادة لاعتماد التصميم السابق.

## المتبقي
مراجعة المالك للتدفق واللغة وفحص الهاتف الفعلي EN/AR ببياناته. الترحيل الإضافي للتدريب والاسم لم يُطبّق على مزوّد؛ يلزم تحققه في بيئة اختبار مصرح بها قبل نشر واجهة مفعّلة. تفاصيل الترحيل في [الإعداد](PILOT_SUPABASE_SETUP.md)، والأدلة في RAD-058 ووصف PR، دون تقرير أو قائمة منفصلة.

## الحدود والعوائق
الفحص المحلي الاصطناعي لا يثبت العزل الحي أو النشر أو الهاتف الفعلي. عوائق Access وبقية تحقق المزوّد باقية في مهامها. المشرف مستقبلي دون دور أو صلاحيات مضافة الآن؛ Assess وO106–O108 وRAD-056 مؤجلة ولا تمنع التدريب. الفحوص والصور والتحسين البصري المستقل مؤجلة.

## المتابعة
راجع وصف RAD-058 ودليلها وجهة انتظارها معًا؛ لا تُغلق من وجود المسودة أو نجاح الفحوص وحده. لا نشر أو تطبيق إنتاج أو تغيير مزوّد دون إذن لاحق. يبقى التسليم Draft فقط؛ حقائق Git/PR تُقرأ بأدواتها، وبقية المهام بجهات انتظارها في [الحالة](project-status.md).
