# التسليم الحالي — تجهيز C/D على مشروع RAD-LAB الأصلي

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم شغّل `npm run docs:context` وتحقق من PR المعني وCI والنشر عبر GitHub، و`npm run status:summary -- --query assess`. الحالة في [project-status](project-status.md) وحده؛ مراجع Git المحلية ليست دليل نشر.

## الهدف والمنجز
D في المسودة بعد دمج C؛ [تقرير D](ASSESS_D_REPORT_2026-10-20.md) يحفظ واجهتها وفحوصها. بعد خطة staging اختار المالك صراحةً الاستكمال على المشروع الأصلي vlacestfruxooznrcjqc. [الخطة](ASSESS_STAGING_PLAN.md#المسار-الجاري-بعد-اختيار-المالك-للأصلية) توثق تغيير الوجهة وحزمة C/D المحلية المراجعة واختبار المعاملة وحدودها؛ اقتراح staging السابق لم يعد الخطوة الفورية. لا حذف للمشروع الجديد، ولا طلب إعادة اعتماد قرارات Assess أو Blueprint أو E/F.

## الخطوة التالية
أرسل المالك فحص B-only ناجحًا واختار المتابعة دون نسخة جديدة، ثم أبلغ «Success. No rows returned» لتشغيل [حزمة C/D](../supabase/manual/assess-original-cd-install.sql). لا تعِد الحزمة أو فحص البداية الذي يفترض غياب C/D. الخطوة التالية على الأصلية: [جرد B/C/D والصلاحيات](../supabase/checks/assess-staging-ready.sql)، ثم [فحص D والبوابة المغلقة](../supabase/checks/assess-mixed-ready.sql)، كل منهما للقراءة فقط؛ تسمية staging تاريخية وتوجيه المالك الحالي يجيز فحوص القراءة على الأصلية. نتائج الفحصين لم تصل بعد. بعدها خدمة الحسابات والإثبات المناسب؛ النجاح المبلغ عنه لا يثبت runtime أو ledger تلقائيًا. تفاصيل الدليل واستثناء النسخة في الخطة؛ لا نعتبر الاسترداد جاهزًا. لم ينفذ الوكيل SQL بعيدًا.

## العوائق والحدود
فحص البداية منقول من المالك وناجح؛ النسخة الحديثة وتجربة استعادتها غير متوفرتين وتُركتا باختيار المالك لهذه العملية؛ تطبيق C/D ناجح بإفادة المالك لكن الجرد/الخدمة غير متحققين بعد، والبوابة لم تُفتح. لا تغيير PILOT_SCHEMA_VERIFIED أو pins أو workflow لمجرد تمرير Deploy؛ بعد SQL يلزم catalogue والبوابة المغلقة وفحص الخدمة بالحسابات قبل مراجعة الإثبات. اختيار الأصلية لا يأذن بنشر Node/عامل/جدولة أو فتح إطلاق أو دمج PR. O106 للموافقة والاحتفاظ/النسخ والاستعادة وغير المؤقت، وO108 قبل محتوى حقيقي وخلفيته ومعاييره وMarker؛ التدريب والتصفير مستقلان. لا فتح/مشاركة معاينة مستضافة من الوكيل، ولا انتقال تلقائي إلى E.
