# التسليم الحالي — تحضير بيئة اختبار Assess

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم شغّل `npm run docs:context` وتحقق من PR المعني وCI والنشر عبر GitHub، و`npm run status:summary -- --query assess`. الحالة في [project-status](project-status.md) وحده؛ مراجع Git المحلية ليست دليل نشر.

## الهدف والمنجز
D في المسودة بعد دمج C؛ [تقرير D](ASSESS_D_REPORT_2026-10-20.md) يحفظ واجهة الأسئلة المنوعة وفحوصها وحدودها. بعد توقف النشر أذن المالك بتحضير خطة وأوامر فحص محلية فقط. [خطة staging](ASSESS_STAGING_PLAN.md) هي حزمة المراجعة الحالية: preflight بلا اتصال، catalogue قراءة فقط واختباره على PGlite، فصل إعدادات المعاينة المقترح، وعقد runtime/worker/الجدولة ومصفوفة القبول. نتائج QA المنفذة وغير المنفذة في الخطة؛ لا إعادة فحوص المنتج الناجحة دون تغيير منتج. قرارات Assess محسومة في [مرجعها](DECISIONS.md#assess-owner-2026-10-19)؛ لا Blueprint شامل أو E/F.

## الخطوة التالية
راجع خطة التجهيز، ثم حدد مشروع staging ومزود Node وregion/tier/حد الإنفاق والصلاحيات قبل إذن خارجي محدد. لا موارد/SQL مزود/runtime/عامل/جدولة أو فتح launch_gate أو ready/merge من إذن التحضير المحلي. workflow الحالي يشارك متغيرات Supabase بين PR وmain؛ لا تغيرها إلى staging. الخطة تقترح STAGING variables بلا fallback ومشروع Pages محميًا مستقلًا، ولم تنفذ أيًا منها. لا تستخدم checker B المثبت على الإنتاج أو bootstrap Auth المحلي لتجهيز staging.

## العوائق والحدود
CI السابق ناجح وDeploy Pages توقف عند حارس المخطط قبل البناء والرفع. C/D متطلبات فعلية؛ إثبات B لا يكفي ولا يتغير لتمرير النشر. لم يُجهز مشروع اختبار أو profile أو ربط Node والعامل؛ بوابة launch مغلقة. catalogue لا يثبت قيمة البوابة أو Auth/Data API/runtime أو مطابقة body SQL؛ يتبعه فحص D المغلق وفحص الحسابات والقبول الحي بإذن محدد. O106 للموافقة والاحتفاظ/النسخ والاستعادة، وغير المؤقت محجوب؛ O108 قبل كل محتوى حقيقي وخلفيته ومعاييره واعتماديات Marker. لا فتح/مشاركة معاينة مستضافة من الوكيل. لا انتقال تلقائي إلى E.

## التدريب والتصفير المستقل
التدريب ومتابعة المتدربين وهوية المقارنة محفوظة بأدلة RAD-058؛ لا تعِد ترحيلًا أو فحص خدمة أو رسمًا دون تغير ذي صلة. تصفير Practice القديم مؤجل واختياري؛ لا حذف معتمد. عند استئنافه اتبع [إجراء التجهيز](PILOT_SUPABASE_SETUP.md#practice-optional-reset): catalogue وعدّ حي ونسخة مجرّبة ومنع كتابة ثم اعتماد حذف محدد. Assess لا يبدأ بحذف التدريب.
