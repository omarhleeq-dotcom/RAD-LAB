## ملخص الحالة

- **الاتجاه الحالي:** أفاد المالك بنجاح مسار P1 كاملًا على الإنتاج بحسابَي اختبار؛ المطلوب تحسين الاستخدام F1–F8. [تقرير A](RAD-085_P1_USABILITY_A_2026-10-28.md) يوثق الواجهة واختبارات الانحدار؛ [القرار](DECISIONS.md#rad085-p1-usability-owner-2026-10-28) يحدد فصل A عن B.
- **ينتظر المالك:** مراجعة الواجهة؛ ثم mini DB day الخاص بـB قبل علامته، وتأكيد حذف النسخ وإفراغ المهملات حسب الإجراءات السابقة.
- **ينتظر مراجِعًا:** QA الواجهة وحدود الأسماء، ونقل SQL والتراجع في B؛ تبقى مراجعات الأمن/ACL والحقوق والمزوّد والقبول وخصوصية Auth بلا FK.
- **مرجع Git:** docs:context للحالة الحالية، ووصف كل Draft لدليل CI/Pages وQA. لا فتح أو مشاركة روابط المعاينة المستضافة.
- **مخاطر معلنة:** رمز A طويل والأسماء غير المتاحة محايدة؛ B يحتاج قاعدة محدثة قبل علامته. [قاعدة الهاتف](DECISIONS.md#rad085-mobile-sql-owner-2026-10-28) مستمرة، ورافع السقف RAD-082؛ RAD-059/RAD-082 قبل أول امتحان حقيقي.
