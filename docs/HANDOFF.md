# التسليم الحالي — جرد أدلة المهام

## نقطة البداية
ابدأ من [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task). شغّل `npm run docs:context` لحقائق Git المحلية و`npm run status:summary` للمهام من مصدرها. للتحقق من PR استخدم `npm run docs:context -- --pr NUMBER` أو أداة GitHub المتصلة؛ تعذّر الوصول يعني أن الحالة غير متحققة.

## المتبقي
اختر المهمة التالية صراحةً من [الحالة](project-status.md) واقرأ دليلها. لا تطلب إعادة نسخة/موافقة/حفظ ثبتت بحدودها، ولا تعممها على بنود خارج نطاقها. المتبقي موجود في المهام نفسها، دون تقرير أو قائمة تحقق إضافية.

## العوائق والحدود
المراجعات الطبية/العربية والبنود الخارجية تبقى في الحالة مع جهة انتظارها. التجميد وتأجيل البرمجة لا يُرفعان بتنظيف الوثائق؛ لا إعادة لاعتماد التصميم ولا استئناف منتج تلقائي.

## المتابعة
قبل التسليم، راجع حالة كل مهمة تغيّرت مع وصفها ودليلها وجهة انتظارها، ثم راجع هذا الملف كاملًا. لا تنسخ هنا الفرع أو SHA أو إصدار الحالة أو نتائج الفحوص أو طلب دمج PR؛ تُقرأ الحقائق المتغيرة بأدواتها، تبقى أدلة المهام في إحالاتها ودليل إنجازها، وملخص الدفعة في وصف PR.
