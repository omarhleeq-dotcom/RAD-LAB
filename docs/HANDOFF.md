# التسليم الحالي — توافق قاعدة التدريب

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context` و`npm run status:summary -- --id RAD-058`. إذن المالك في [S-MY-ATTEMPTS-1](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط) يشمل إصلاح تشخيص غياب تحديث قاعدة التدريب ومنع نشر رابط غير متحقق منه.

## المتبقي
التحقق من مسار الخدمة بعد إفادة المالك بنجاح تطبيق ترحيل التدريب وفحصه داخل المعاملة على المشروع المطابق للبناء. يلزم [مسار التحقق](PILOT_SUPABASE_SETUP.md#training-deployment-check): قراءة الملف الشخصي وRPC بحساب مشارك ومالك، ورفض اختيار مستخدم آخر للمشارك، ثم تسجيل إثبات التوافق وإعادة تشغيل النشر المصرّح به. لا تعِد تطبيق الترحيل. بعده مراجعة المالك للتدفق واللغة والهاتف الفعلي. الأدلة في RAD-058 ووصف PR، دون تقرير أو قائمة منفصلة.

## الحدود والعوائق
حارس النشر يتحقق من إثبات يدوي مرتبط بالمشروع ومحتوى SQL، ولا يتصل بالقاعدة أو يكشف الانحراف الحي خارج Git. غياب الإثبات يحجب البناء والرفع الجديدين ويستبدل تعليق الرابط برسالة حجب؛ الروابط القديمة تبقى على نسختها. لم تُغيّر إعدادات المزوّد أو متغيرات GitHub. إذن المالك الصريح شمل ترحيل التدريب على rad-lab-pilot/main؛ نجاح SQL الذي أرسله لا يثبت Auth أو PostgREST أو العزل الحي. لا يوجد اتصال إداري مباشر بالقاعدة من بيئة الوكيل. عوائق Access وبقية تحقق المزوّد باقية في مهامها.

## المتابعة
RAD-058 تبقى للمراجعة مع وصفها ودليلها وجهة انتظارها معًا. المشرف وAssess وO106–O108 والفحوص والصور والتحسين البصري المستقل مؤجلة. التسليم Draft فقط؛ حقائق Git/PR تُقرأ بأدواتها، وبقية المهام في [الحالة](project-status.md).
