# التسليم الحالي — هوية المقارنة وتجهيز التصفير

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context -- --pr 88` و`npm run status:summary -- --id RAD-058`. الأدلة في المهمة ووصف المسودة فقط؛ [العقد](PILOT_SUPABASE_SETUP.md#practice-comparison-version) و[إجراء التجهيز](PILOT_SUPABASE_SETUP.md#practice-optional-reset).

## المتبقي
يلزم استكمال مراجعة المسودة والتحقق من CI للتحديث المقصود دون متابعة دورية. عاد المالك إلى SQL Editor للمشروع المطابق؛ دليل فحص القراءة في RAD-058 ووصف المسودة. ملف تطبيق محروس مشتق من الترحيل والفحصين جاهز لمراجعة المالك وتنفيذه المحدد، ولا يُسجل التطبيق قبل نتيجة COMPARISON_UPDATE_APPLIED. استثناءات الحارسين الأولين والثالث معتمدة ومنفذة بحدودها في [القرار](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط)، دون إذن عام لتغيير توقعات أخرى. فشل النشر عند حارس المخطط مستقل عن الاختبارات؛ لا تعِد تشغيله لتجاوز الحجب قبل الترحيل والتحقق الجديدين.

هوية المقارنة تتطلب ترحيلًا إضافيًا لم يُطبق إنتاجيًا. لا تُعد تشغيل ترحيل التدريب والاسم السابق. التنفيذ التالي هو ترحيل المقارنة وحده بمعاملة كاملة تتوقف عند مخطط جزئي أو إعادة التنفيذ؛ لا إعادة لترحيل الاسم والتدريب أو حذف أو backfill. قبل أي تطبيق جديد يلزم إذن إنتاج محدد؛ بعده فحصا الجاهزية ومسار الخدمة الجديد للحسابين، ثم تسجيل إثبات مطابق وفق [إجراء النشر](PILOT_SUPABASE_SETUP.md#training-deployment-check). إجراء [فحص الخدمة الجديد](PILOT_SUPABASE_SETUP.md#comparison-owner-service-check) جاهز للحاسوب بعد الترحيل وفحصي catalogue؛ يشغله المالك ثم المشارك ويقدمان سطرين منقحين بزوج متطابق. هوية فارغة في صف تاريخي تثبت إتاحة الحقل فقط، لا كتابة جديدة أو نجاح الرسم. أدلة الخدمة والرسم والهاتف السابقة محفوظة بحدودها، ولا تعاد فحوص ناجحة دون تغيير ذي صلة.

اختار المالك جميع محاولات Practice للمعاينة فقط؛ لا حذف معتمد. يشغل المسؤول فحص catalogue والعدّ والمعاينة محليًا على المشروع المطابق، ويحفظ المخرجات التفصيلية والنسخة خارج Git والمحادثة. يلزم عدّ المحاولات وfeedback والأحداث، ونسخة مجرّبة الاستعادة ومنع كتابة فعلي للنسخ القديمة قبل تجهيز واعتماد حذف محدد. لا SQL حذف قبل catalogue الحي، ولا درجات افتراضية لاختبار النظافة.

## الحدود والعوائق
لا اتصال إداري أو بيانات اعتماد مهيأة للوكيل؛ لا عدّ أو نسخة حية منفذة. الحسابات والأسماء والأدوار والموافقات محفوظة، والأحداث مقترح إبقاؤها بعد مراجعة أثرها. نجاح المسودة لا يحدّث main أو الروابط القديمة؛ التنظيف ليس علاج الرسم ولا شرط حفظ التاريخ.

حارس النشر يبقى فعالًا ويحجب إثبات SQL القديم بعد تغيره؛ لا تسجيل إثبات أو نشر main أو تغيير سياسات إنتاج تلقائي. الهاتف الفعلي للمالك؛ لا فتح أو مشاركة معاينة مستضافة من الوكيل.
