# التسليم الحالي — RAD-085 / DB day مكتمل

اقرأ [AGENTS](../AGENTS.md)، ثم docs:context وstatus:summary -- --id RAD-085. [project-status](project-status.md) مصدر الحالة الوحيد. اعمل في checkout نفسه دون worktree/subagents.

## ملخص الحالة
- **الاتجاه الحالي:** DB day مكتمل بإفادة المالك، مع إصلاح نقل الدوال والمُهيّئ والجاهزية والدخان. [تقرير الإتمام](RAD-085_DB_DAY_COMPLETED_2026-10-28.md) يحفظ الدليل وحدوده والتحقق المنفّذ وغير المنفّذ؛ [الحزمة](RAD-085_DB_DAY_P1.md) مرجع تاريخي لا طلب إعادة تنفيذ.
- **ينتظر المالك:** ضبط PILOT_SCHEMA_VERIFIED بالقيمة الجديدة في #144 المحدّث، ثم قراره بدمج #144، وبعد النشر اختبار P1 على الهاتف بحسابَي اختبار. تأكيد حذف النسخ وإفراغ المهملات.
- **ينتظر مراجِعًا:** أدلة النقل والترقية والأمن/ACL والحقوق والمزوّد والقبول. سجلات Auth بلا FK بند خصوصية مفتوح؛ لا إغلاق له بنجاح الجرد.
- **مرجع Git:** docs:context لحالة الفرع وDraft PR؛ وصف PR لدليل QA/CI على الرأس النهائي. لا نسخ للـmarker إلى التسليم.
- **مخاطر معلنة:** البوابة مغلقة والتراجع لم يُشغّل. [قاعدة الهاتف](DECISIONS.md#rad085-mobile-sql-owner-2026-10-28) لازمة لأي SQL حي مستقبلي؛ السقف SQL حي يدوي من الهاتف ورافعه مسار اللابتوب/CLI في RAD-082. RAD-082 وRAD-059 لازمان قبل أول امتحان حقيقي.

## الخطوة التالية والعوائق
مسار المالك التالي: marker الجديد ثم قراره بدمج #144 ثم هاتف P1 بحسابَي اختبار؛ لا إعادة إزالة التجربة أو M1–M4 أو المُهيّئ. التراجع الأصلي معرّض لخطر لصق الهاتف؛ companion ومولد النقل مقترحان غير منفذين، وتفاصيل المراجعة والاختبار في تقرير الإتمام. [S7](RAD-085_REMAINING_OPERATIONS_2026-10-26.md#s7-supervisor-restore) قائم: استعادة الحساب لا تعيد تعيين المشرف أو مجموعاته.

برومبت المتابعة: «اقرأ AGENTS وHANDOFF وتقرير الإتمام؛ تحقق من Drafts وCI مباشرة دون polling. DB day مكتمل والبوابة مغلقة؛ تابع نتيجة ضبط المالك marker وقراره بشأن #144 وهاتف P1 بحسابَي اختبار. لا SQL حي أو Variables أو نشر أو ready/merge من الوكيل. لا بيانات مشاركين أو بريد أو معرّفات أشخاص في الملفات».
