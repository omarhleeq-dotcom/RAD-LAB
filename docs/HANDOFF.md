# التسليم الحالي — Assess D: الأسئلة المنوعة

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم شغّل `npm run docs:context` وتحقق من PR المعني وCI والنشر عبر GitHub، و`npm run status:summary -- --query assess`. الحالة في [project-status](project-status.md) وحده؛ مراجع Git المحلية ليست دليل نشر.

## الهدف والمنجز
دُمجت C وحارس النشر في #91، ثم أذن المالك صراحةً بـD فقط. [قرارات المالك](DECISIONS.md#assess-owner-2026-10-19) تبقى المرجع دون إعادة اعتماد أو Blueprint شامل. اقرأ [تقرير D](ASSESS_D_REPORT_2026-10-20.md) و[العقد](ASSESS_FOUNDATION.md) و[الخطة](ASSESS_IMPLEMENTATION_PLAN.md): واجهة الاختبارات المسندة، runner إنجليزي لsingle-choice وsimulator-part، أدوات/مشهد انتقائية وحفظ/مصالحة وقفل تعريض وتسليم، ومحرر publication JSON ثابت للمالك. المحتوى الحقيقي غير منشور؛ عينات هندسية محلية فقط. لا مسار E أو سجل F جديد.

## الخطوة التالية
نجح CI للمسودة؛ توقف Deploy Pages عند حارس المخطط قبل البناء والرفع، كما يثبت سجل GitHub في تقرير D. راجع المسودة وحدود العرض/التحقق؛ ثم حدد تجهيز بيئة اختبار بإذن مستقل وفق [إعداد D](PILOT_SUPABASE_SETUP.md#assess-d-local). لا تشغيل عامل أو SQL إنتاج أو فتح launch_gate أو ready/merge تلقائي. واجهة D تستدعي C فعلًا؛ [عقد النشر](DEPLOYMENT.md#عقد-متطلبات-الواجهة--فصل-النشر-عن-الخدمات-الخلفية) يطلب C/D، وإثبات B القديم لا يكفي. حظر النشر إلى مشروع غير مجهز صحيح؛ لا تغير PILOT_SCHEMA_VERIFIED أو تعيد تصنيف C مؤجلة أو تتجاوز الحارس لتمريره. نتائج الفحوص المنفذة/غير المنفذة والبعيدة في التقرير، لا تُستنتج من بناء محلي.

## العوائق والحدود
C/D غير منشورتين وlaunch_gate مغلقة. مدخل المالك يضع مرشحًا pending خاصًا؛ تثبيته يحتاج Node validator/worker موثوقًا مجهزًا مستقلًا، ولا يثبت مجرد الإرسال إتاحة أو تشغيلًا حيًا. اختيار runtime وJWT/RPC وربط صلاحية العامل وجدولة expiry/purge والمراقبة والتنبيه والاسترداد والموافقة والاحتفاظ/النسخ والاستعادة O106 باقية؛ غير المؤقت محجوب. O108 للمصادر والترخيص والمراجع والخلفية والمعايير واعتماديات Marker قبل أي سؤال حقيقي. الرسم الانتقائي الحالي هندسي محدود، لا اعتماد تشريحي أو طبي. لا انتقال تلقائي إلى E.
