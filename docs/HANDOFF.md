## الهدف والمتبقي

F محلية للمراجعة: سجل داخل Assess بأربعة حقول، حجب خادمي وقراءة محدودة، وموافقة مستقلة EN/AR وحاجز إنشاء محاولة. حذف الستة أشهر التقويمية وصيانة C معاد استخدامهما دون job مكرر. لا تفاصيل إجابات أو مراجعة معايير/تحليلات أو تغيير Practice.

## الخطوة التالية
راجع F ونصوص الموافقة و[عقد النشر](DEPLOYMENT.md#assess-f-contract) و[خطة التجهيز](ASSESS_STAGING_PLAN.md#assess-f-next). يتطلب اتصال F SQL إضافية، ولذلك رفض إثبات E القديم صحيح؛ لا تعديل PILOT_SCHEMA_VERIFIED أو pins لتجاوز الحارس. لا SQL أو runtime/عامل/schedule على الأصلية دون إذن مستقل، مع نسخة حديثة واسترداد قبل أي تغييرات F؛ استثناء النسخة السابق خاص بعملية E الماضية. PR مسودة فقط، بلا ready/merge أو فتح launch_gate.
