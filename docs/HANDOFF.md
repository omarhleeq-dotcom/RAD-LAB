## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم docs:context وstatus:summary لـRAD-085؛ [project-status](project-status.md) وحده مصدر الحالة. تحقق مباشرة من#137: open/Draft/unmerged؛ إذا أُغلق أو دُمج فتوقف وأبلغ المالك قبل بديل. استمر في checkout نفسه دون worktree/subagents أو ready/merge/auto-merge. لا لابتوب/هاتف/Windows/WSL أو hosted preview مطلوب لهذا العمل المحلي.

## ملخص الحالة
- **الاتجاه الحالي:** [التدقيق الداخلي](RAD-085_SECURITY_AUDIT_2026-10-26.md) أصلح انتهاء الجسر بعد الأقفال وحذف العضوية المتسلسل، وجرّب الترقية وفشل كل معاملة والنسخ والاستعادة صناعيًا. [حزمة التطبيق](RAD-085_APPLICATION_PACKET_2026-10-26.md) للمراجعة بشروط توقف؛ لم تُطبق حيًا.
- **ينتظر المالك:** مراجعة P1/P2 والجسر والإسناد والإغلاق والهاتف؛ مسؤول إدخال مراجعات حقيقية وسياسة مشاركة وقرارات الاحتفاظ وهوية النقل لاحقًا. ملفات جلسة الهاتف الغائبة لم تُستعد أو تعطل العمل.
- **ينتظر مراجِعًا:** ACL/التزامن والمحو والاحتفاظ ونسخ المزوّد واستعادته والمحتوى والمصادر والرخص وO108 وMarker والحمل والتكلفة والقبول. هذه مراجعة داخلية لا تغلق المراجعات المستقلة أو RAD-063 أو RAD-060 آليًا.
- **مرجع Git:** docs:context للرأس والحالة الفعلية، والتقرير للمنفذ وحدوده ووصف PR لدليل CI وتخطي النشر على الرأس نفسه؛ لا نجاح رأس سابق أو نشر/هاتف مفترض.
- **مخاطر معلنة:** FK الروابط والمراجعات تمنع محوًا غير مخطط؛ لا إجراء احتفاظ/محو تشغيلي معتمد لها. مخزن المراجعات والمشاركة والنقل وLOGIN الجسر والإبطال الحي غير مهيأة؛ الأداء وFREE غير مثبتين.

## الخطوة التالية
اقرأ الحزمة والعقود ثم جهّز نطاقًا محليًا محددًا لتصميم هوية اتصال الجسر المحدودة وإبطالها، منفصلة عن العامل، مع رفض SET/INHERIT غير المأذون والإبطال الفعلي للجلسات وpooler/cache ومصالحة ACK. لا تفعّل LOGIN أو تنشئ سرًا حيًا من هذه الخطوة. قبل العامل يلزم مطابقة worker/case/evaluator والصورة الحالية وIAM/STOP والمراقبة والتكلفة والنسخ وإذن مستقل.

الاستثناء الجديد RAD085-SQL-AUDIT-EXPIRY-DELETE-20261026 وافق عليه المالك بعد الفرق والأدلة؛ طُبق محليًا على الأول والثالث وبصمتيهما فقط. [ملف الفرق](RAD-085_SQL_AUDIT_PROPOSAL_2026-10-26.patch) دليل الاستثناء المطبق، لا migration رابعة ولا إذن دائم. لا إعادة طلب موافقته، ولا تغيير توقع أو بصمة أخرى تلقائيًا.

إعادة الشاهد والاعتماديات وحدود أدوات dump في التقرير؛ اختبار Node الجديد مستقل عن CI القائمة. [دليل الجسر السابق](RAD-085_ASSIGNMENT_BRIDGE_REPORT_2026-10-26.md) يحفظ دورة المسودة→مراجعة هندسية→تثبيت وربط→إسناد وإغلاق؛ لا تحويل SYNTHETIC إلى مراجعة فعلية. استعلام الجرد الجديد منفصل ولا يولد شهادة توافق.
