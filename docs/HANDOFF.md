# التسليم الحالي — حزمة تشغيل Assess المحلية المغلقة

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، وشغّل `npm run docs:context` مع تحقق GitHub لـPR #95 والمسودة الحالية وأحدث main وCI/Pages على رأسه نفسه، ثم `npm run status:summary -- --id RAD-056`. [project-status](project-status.md) المصدر الوحيد للحالة؛ أرشيف التقارير ليس أمرًا لإعادة العمل. استخدم checkout معزولًا واحفظ أي عمل قائم.

## الهدف والمنجز
دُمجت F في #94 ونجح CI وPages على main المدموج وفق التحقق في [تقرير الحزمة](ASSESS_LOCAL_OPERATIONS_REPORT_2026-10-20.md). #95 مسودة توثيق غير مدموجة عند القراءة؛ تحوي إفادة أحدث من المالك بنجاح عرض الهاتف عمومًا، دون إثبات لغات/حسابات/تدفقات لم يفصلها. اكتملت الحزمة المحلية المستقلة: تشغيل محدود بقاعدة اصطناعية قابلة للإتلاف، وتوقف تعاوني، وفحوص تنافس/lease وفشل/استرداد وحذف عبر خدمة C وRPCs القائمة. أضيف دليل SIGINT/SIGTERM فعلي خلال التهيئة ورفض فشل إعداد منقح؛ حدوده ونتيجة نشر الرأس البرمجي في تقرير المتابعة، ولا يُفترض نجاح CI أو رأس أحدث. [الدليل](ASSESS_LOCAL_OPERATIONS.md) يحدد الإعداد والإيقاف وحدود Node/PGlite/PostgreSQL؛ لا endpoint أو عامل/schedule منشور أو قبول حي.

## الخطوة التالية
مراجعة المسودة ثم تحديد نطاق مستقل لتجهيز runtime وبنائه وربط الهوية وصلاحية العامل والجدولة والمراقبة بإذن لاحق. لا اختيار مزود إنتاج من نجاح محلي، ولا إعادة اعتماد الستة أشهر أو الحقول الأربعة أو سياسة العلامة أو المسارين. لا SQL جديدة على الأصلية أو تغيير PILOT_SCHEMA_VERIFIED/pins أو نشر runtime/عامل/schedule أو فتح launch_gate أو ready/merge. نتائج QA الفعلية وما لم يُختبر وروابط الأدلة في التقرير.

## العوائق وحدود الأدلة
O106: احتفاظ غير المؤقت المتروك، أعمار metadata الحجز/الموافقة، اعتماد الموافقة وإجراءاتها، ودورة النسخ/التصدير/الحذف بعد restore وتجربة الاسترداد؛ غير المؤقت محجوب. O108 للمصادر والترخيص والمراجعة والخلفية والمعايير وMarker مستقلة. runtime والعامل والجدولة والمراقبة والموافقة والاحتفاظ والنسخ والاستعادة بوابات مستقلة. SQL وPages والخدمة المغلقة والهاتف العام لا تثبت الإسناد والحفظ والانقطاع والتسليم والتصحيح حيًا؛ القبول التجريبي الحي غير مكتمل والبوابة مغلقة.

## التدريب والأدلة السابقة
Practice وسلوكه ودرجاته وصوره وبياناته وتوقعاته وبصماته محفوظة. SQL F وجردها وفحصها وزوج الخدمة المغلقة مثبتة بإفادة المالك؛ runtimeOrLaunchVerified=false مقصودة، والتفصيل في [تقرير F](ASSESS_F_REPORT_2026-10-20.md#f-closed-pair-attestation). لا إعادة B/C/D/E/F أو أدوات الحسابين أو CRLF دون تغير ذي صلة، ولا محتوى/محاولات/موافقات إنتاجية للشاهد. استثناء الاسترداد السابق للعملية الماضية وحدها، لا إذن مستقبلي. تصفير Practice مؤجل مستقل ولا حذف له هنا. عند تداخل توثيق #95 تُدمج أدلة الحالة والتسليم مع المتبقي الأحدث دون استبداله.
