## ملخص الحالة
- **الاتجاه الحالي:** SQL محلي جزئي كُتب واختُبر على PostgreSQL معزول؛ توقف التوسع عند توقعات قائمة إضافية. [تقرير SQL](RAD-085_SQL_REPORT_2026-10-26.md) يحصر النجاح والفشل والتغطية غير المكتملة، و[العقود](RAD-085_SQL_CONTRACTS_2026-10-26.md) ترتب الترحيلات ومتطلبات التطبيق اللاحق.
- **ينتظر المالك:** استثناءات مسماة للتوقعات/fixtures غير المعدلة كما في التقرير؛ أُجيز F وحده. مراجعة P1/P2 والهاتف مؤجلة إلى ما بعد SQL والربط الفعلي ونسخة متصفح، ولم تحصل المراجعة أو الموافقة؛ لا إذن تشغيل حي.
- **ينتظر مراجِعًا:** التفويض والتزامن والموافقة والجسر المراجع وتطابق العامل/case/evaluator والمقياس والمصادر والرخص وO108 والنسخ/restore والأداء والقبول. RAD-060 سطح SQL محلي فقط؛ الزر والربط والقبول متبقيان.
- **مرجع Git:** docs:context للحالة الراهنة؛ تقرير SQL لأدلة هذه الدفعة، وتقارير الواجهات تاريخية دون إعادة QA. لا CI أو نشر أو هاتف مفترض.
- **مخاطر معلنة:** سياسة المشاركة وسجل refs غير مهيأين، ولا API لتثبيت publication. قفل نطاق عالمي يسلسل التغييرات ويحتاج قياسًا؛ التخزين والاحتفاظ والحذف والتغطية غير مكتملة. لا جاهزية إطلاق أو اكتمال SQL من الفحوص الجزئية.

## الخطوة التالية والعوائق
اقرأ قائمة الفشل الفعلية في التقرير قبل تحرير أي توقع. بعد الإذن المسمى المناسب أعلن ميزانية منقحة، ثم استكمل اختبارات النتائج والإصدارات والسباقات والانتهاء والحذف والتغطية وعالج مشاكل التنفيذ دون تخفيف حراس أو رفع مهل. راجع الترحيلات الثلاثة بالترتيب الموثق؛ لا تعِد إنشاء المجموعات/العضويات/الإسناد/الإغلاق القائمة، ولا تعِد migrations مثبتة.

حاضنة الاختبار تحتاج PostgreSQL وpg تحت /tmp/radlab-ops-postgres كما في التقرير، ومكتباته المرفقة وsymlinks؛ تستعمل Unix socket فقط وتفشل صراحة عند غياب الاعتماد. يلزم حسم تجهيز lane PostgreSQL في CI قبل الدمج دون skip أو قبول PGlite المتسلسل بديلًا للتزامن. فحوص المصدر لا تثبت الخدمة أو Supabase.
