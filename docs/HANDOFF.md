# التسليم الحالي — إصلاح الرسم وبداية تدريب نظيفة

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context` و`npm run status:summary -- --id RAD-058`. النطاق وقرار المالك في [S-MY-ATTEMPTS-1](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط)؛ أدلة هذه الدفعة وحدود فحوصها في المهمة ووصف المسودة فقط.

## المتبقي
حسم حد بصمة التعريف التي تشمل النصوص: إبقاؤها مع توثيق الحد، أو نطاق مستقل لهوية مقارنة تحفظ الأصل؛ لا تغيير خفي للخوارزمية. [عقد الإصدار وصيانته](PILOT_SUPABASE_SETUP.md#practice-evaluation-version) يوضح حدود الضمان اليدوي.

يلزم استكمال مراجعة المسودة؛ أدلة الفحوص المستوفاة وحدودها في RAD-058 ووصف المسودة. لا تُطلب إعادة الفحوص الناجحة دون تغيير ذي صلة، ولا إعادة ترحيل التدريب. لا فتح أو مشاركة معاينة مستضافة من الوكيل.

شبكة بيئة الوكيل لا تسمح بمشروع Supabase ولا توجد جلسات مهيأة؛ أي فحص حي إضافي يحتاج تشغيل المالك دون مشاركة كلمات مرور أو رموز جلسة. إثبات النشر مرتبط بالمشروع وSQL ويحتاج إعادة تحقق إذا تغيرا أو استُعيدت القاعدة؛ [حدود الحارس](PILOT_SUPABASE_SETUP.md#training-deployment-check) باقية.

التصفير اختياري وغير معتمد: يلزم تحديد جميع محاولات Practice أو حسابات محددة، ثم فحص catalogue الحي وعدّ المحاولات والملاحظات والأحداث المرتبطة واستعلامات معاينة محدودة ونسخة قابلة للاسترجاع. قبل اعتماد حذف محدد، تحقق من وصول الكاتب المصحح لكل نسخة مستخدمة وحدد نافذة توقف الكتابة أثناء التنظيف؛ الملاحظات مرتبطة بحذف متتابع، والأحداث تربط المحاولة داخل JSON. أبقِ الحسابات والأسماء والأدوار والموافقات. لا اتصال إداري مباشر هنا؛ يجهّز الإجراء للمالك إذا لم يتوفر. لا حذف أو إعادة ختم للماضي، ولا اختبار نظافة حي قبل الاعتماد والتنفيذ الفعليين.

## الحدود والعوائق
حارس النشر يبقى فعالًا؛ نجاح SQL لا يضبط متغير GitHub، والفحوص المحلية ليست Auth/PostgREST أو عزلًا حيًا. غياب الإثبات يحجب البناء والرفع الجديدين؛ لا تستخدم تسجيله لتجاوز التحقق. عوائق Access وبقية تحقق المزوّد باقية في مهامها. لا معاينة مستضافة من الوكيل.

## المتابعة
RAD-058 تبقى للمراجعة مع وصفها ودليلها وجهة انتظارها معًا. المشرف وAssess وO106–O108 والفحوص والصور والتحسين البصري المستقل مؤجلة. التسليم Draft فقط؛ حقائق Git/PR تُقرأ بأدواتها، وبقية المهام في [الحالة](project-status.md).
