# التسليم الحالي — اتساق الوثائق

## نقطة البداية
ابدأ من [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task). شغّل `npm run docs:context` لحقائق Git المحلية و`npm run status:summary` للمهام من مصدرها. للتحقق من PR استخدم `npm run docs:context -- --pr NUMBER` أو أداة GitHub المتصلة؛ تعذّر الوصول يعني أن الحالة غير متحققة.

## المتبقي
راجع [تقرير اتساق الوثائق](DOCS_CONSISTENCY_REPORT.md) وأدلة التحقق عند متابعة هذه الدفعة. اختر المهمة التالية صراحةً من [الحالة](project-status.md)؛ لا تستنتجها من تقرير قديم أو من حالة PR مكتوبة سابقًا.

## العوائق والحدود
المراجعات الطبية/العربية والبنود الخارجية تبقى في الحالة مع جهة انتظارها. التجميد وتأجيل البرمجة لا يُرفعان بتنظيف الوثائق؛ لا إعادة لاعتماد التصميم ولا استئناف منتج تلقائي.

## المتابعة
قبل التسليم، راجع حالة كل مهمة تغيّرت مع وصفها ودليلها وجهة انتظارها، ثم راجع هذا الملف كاملًا. لا تنسخ هنا الفرع أو SHA أو إصدار الحالة أو نتائج الفحوص أو طلب دمج PR؛ تُقرأ الحقائق المتغيرة بأدواتها، وتبقى أدلة الدفعة في تقريرها.
