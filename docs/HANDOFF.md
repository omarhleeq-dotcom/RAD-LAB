# التسليم الحالي — RAD-069 C1: لوحة المالك

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم `npm run docs:context -- --pr NUMBER` و`npm run status:summary -- --id RAD-069` و`--id RAD-044`. [project-status](project-status.md) مصدر الحالة الوحيد. استمر في checkout نفسه بلا worktree أو subagents؛ PR مسودة فقط، وبلا اشتراك أو polling أو معاينة مستضافة.

## ملخص الحالة
- **الاتجاه الحالي:** C1 منفذة للمراجعة: تبويبات URL، دليل مشاركين مشترك مرقم وبحث خادم، مرشحات محلية وعرض/CSV للملاحظات، ملخصات محفوظة بترحيل إضافي، وإعادة تنظيم Assess؛ [القرار](DECISIONS.md#rad069c-owner-2026-10-24) و[التقرير](RAD-069C1_REPORT_2026-10-24.md).
- **ينتظر المالك:** تطبيق SQL/التحقق/الإثبات يدويًا وفق [دليل C1](PILOT_SUPABASE_SETUP.md#owner-dashboard-c1)، وفحص الهاتف وCSV الملاحظات القائمة. تصميم الحذف في §7 فقط؛ لا تنفيذ قبل قراره. تبقى مراجعات A/B1/B2a ولوحتَي B2b المعدلتين مستقلة.
- **ينتظر مراجِعًا:** لا مراجعة طبية جديدة؛ حدود RAD-019 وO108 والمصادر محفوظة في الحالة. Assess البرمجي والتشغيل مؤجلان؛ هذه إعادة تنظيم فقط.
- **مرجع Git:** عبر docs:context؛ ما شُغّل وما فشل وما لم يُشغّل موثق في [تقرير C1 §6](RAD-069C1_REPORT_2026-10-24.md#6-التحقق)، ولا نجاح CI أو تطبيق حي مفترض.
- **مخاطر معلنة:** خطأ UTC أعيد إنتاجه بعينات وأصلح؛ سبب واقعة RAD-044 الحية غير مثبت دون طلبها الأصلي. fallback محدود لكنه أكثر طلبات، والملخص ينتظر SQL. مرجع حزمة Assess التاريخي ثابت وبصماته لم تتغير. حارس عدد الدوال صُحح بالاستثناء الصريح ونجح؛ لا توسيع للإذن.

## الخطوة التالية والعوائق
- [استثناء الحارس](DECISIONS.md#rad069c-test-exception-2026-10-24) أُذن ونُفذ ونجح؛ لا توسيع له. لا تعِد المجموعة الكاملة التي شُغلت؛ اختبر فقط ما يتأثر بتغييرات جديدة أو فشل غير محلول.
- لا تعِد ترحيلات أو أدوات Assess القديمة؛ SQL الجديدة وحدها بعد مراجعة المالك، ولا يتصل الوكيل بالمشروع الحي. النشر محجوب بالإثبات السابق حتى التحقق والتحديث اليدوي.
- RAD-044 تبقى review: طابق العدد والنص مع CSV بالمرشحات نفسها محليًا؛ لا تشارك بيانات مشاركين أو لقطاتهم. لا تجزم بسبب الملف التاريخي من fixture.
- الحذف متوقف عند التصميم والأسئلة؛ لا زر أو Auth deletion أو تعديل خصوصية دون قرار.
