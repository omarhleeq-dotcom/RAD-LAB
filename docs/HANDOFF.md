## ملخص الحالة
- **الاتجاه الحالي:** معاينة full-practical المحلية تضم PracticalScene وPracticalControls القائمين، بعد فصل بيانات الرسم العامة دون تخفيف الحارس؛ P1 وmixed والإسناد الاصطناعي محفوظة. كل SQL واختباراته الجديدة في جلسة أخيرة واحدة بعد تجهيز الواجهات ومراجعة المالك.
- **ينتظر المالك:** تقييم P1/P2 والهاتف في آخر جلسة تجهيز الواجهات، قبل جلسة SQL المجمعة مباشرةً؛ مؤجل وليس قبولًا أو اكتمالًا ولا يُطلب الآن. تبقى RAD-085 review دون اكتمال التأليف أو الإسناد أو صلاحيات المشرف الحقيقية. متبقي RAD-084/083/080/079/078 وDB day وRAD-077 وA/B/C1 محفوظ.
- **ينتظر مراجِعًا:** قبول المعاينة وO108 والمصادر والرخص والمحاكي وMarker، وإنفاذ نطاق المشرف بالخادم. لا publication أو ContentReview أو اعتماد طبي مخترع؛ RAD-019 مغلقة بدليلها دون مصادقة سريرية جديدة.
- **مرجع Git:** docs:context للحالة الراهنة؛ تقرير المشهد للفحوص المنفذة وغير المنفذة وحدودها؛ لا CI أو نشر أو هاتف مفترض.
- **مخاطر معلنة:** المشهد عرض هندسي قائم بقيم مؤقتة، دون محاولة أو تعريض أو حفظ إجابات أو تصحيح خدمة. الحفظ والإسناد في ذاكرة fixture دون publication؛ صلاحيات العرض ليست عزلًا أمنيًا. الربط والموافقة والعامل والنسخ والقبول بوابات لاحقة.

## الخطوة التالية والعوائق
توقف بعد التسليم حتى توجيه المالك؛ لا طلب تقييم الآن. المراجعة المحلية عند وقتها: `node scripts/qa/rad-085-authoring-audit.mjs --serve`، ثم عنوان loopback المطبوع مع locale=ar أو locale=en. اختر مجموعة ثم إنشاء full-practical المستقل؛ المسودة الحالية واحدة لكل حساب/مجموعة، وإعادة التحميل تمحو الذاكرة. اختبر المشهد والضوابط والتنقل والإغلاق والإسناد وصفحاته والتبديل والإلغاء والتعارض والسحب والانتهاء؛ لا مسار منتج أو hosted preview. التدقيق بالمشهد لكل الفحوص: الأمر نفسه مع --practical دون --serve؛ mixed دون flags، وP1 بأمرها المحفوظ في تقريرها.

قبل الربط: مراجعة المالك بتوقيتها أعلاه والمراجعة المستقلة ومقياس النشر النهائي، ثم جلسة القاعدة المجمعة وقبول التفويض والتزامن والنسخ والعامل وصورة متطابقة مع الإصدارات. أسماء DTO/العمليات المحلية ليست schema أو RPCs نهائية. إن أُغلق PR أو دُمج فتوقف وأبلغ المالك قبل أي بديل؛ يبقى Draft دون ready/merge/auto-merge أوsubscribe/poll.
