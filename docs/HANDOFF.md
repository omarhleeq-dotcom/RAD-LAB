## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم docs:context و status:summary لـ RAD-085 ؛ [project-status](project-status.md) مصدر الحالة الوحيد. تحقق مباشرة من#137: open/Draft/unmerged ؛ إذا أُغلق أو دُمج فتوقف وأبلغ المالك قبل بديل. استمر في checkout نفسه دون worktree/subagents أو ready/merge/auto-merge. توجيه المالك الحالي يجيز العمل المحلي أثناء غياب لابتوبه، دون تشخيص Windows/WSL أو هاتفه.

## ملخص الحالة
- **الاتجاه الحالي:** دورة اصطناعية في PostgreSQL واحد: حفظ revision ومراجعة مستقلة ثم المرشح والتثبيت والربط والتجهيز والتأكيد والإغلاق. [التقرير](RAD-085_ASSIGNMENT_BRIDGE_REPORT_2026-10-26.md) للتحقق والاستثناء المحدد؛ [العقود](RAD-085_SQL_CONTRACTS_2026-10-26.md) للصلاحيات والمطابقة.
- **ينتظر المالك:** مراجعة P1/P2 والجسر والإسناد والإغلاق والهاتف والقبول. التعديلات غير الملتزمة من الجلسة المتوقفة غائبة هنا، ولم تُستعد أو تُحفظ في commit ؛ التقرير يسجل ذلك.
- **ينتظر مراجِعًا:** التفويض والتزامن و O108 والمصادر والرخص والخلفيات و Marker والمشاركة والنسخ/restore والسعة والأداء والقبول. RAD-060 لم تُغلق آليًا بقبول زر محلي.
- **مرجع Git:** docs:context للحالة الراهنة، والتقرير للتحقق المحلي ووصف PR لدليل CI على آخر رأس وتخطي Deploy Pages ؛ لا نجاح رأس سابق أو نشر/هاتف مفترض.
- **مخاطر معلنة:** مخزن المراجعة التشغيلي والسياسة والسجل غير مهيأة؛ القناة غير المهيأة ترفض. الدور الداخلي NOLOGIN بلا عضوية للمستخدم أو العامل، والمنفذ بلا نقل/هوية LOGIN حية. إبطال SSE محلي فقط.

## الخطوة التالية وإعادة المراجعة
مراجعة المالك للدفعة، ثم توجيه مستقل لما يليها. الاستثناء المسمى يخص مصدر migration الثالثة وبصمتها المؤجلة فقط؛ لا توسيع إلى بصمات أو توقعات أخرى. قبل التشغيل يلزم مخزن مراجعة مستقل حقيقي ومسؤول تعبئته، ومشاركة معتمدة وقبول الذات، وهوية نقل موثوقة وإبطال حي، ومراجعات ACL والأداء والسعة والنسخ/restore. لا اعتبار fixture الهندسية اعتمادًا طبيًا أو ترخيصًا أو O108 مكتملة.

إعادة القبول: node scripts/assess/setup-rad085-postgres.mjs ثم node scripts/qa/rad-085-p2-sql-audit.mjs --assignments. خيار--serve على loopback فقط؛ Ctrl-C يغلق الخادم ويحذف قاعدة الاختبار. تهيئ الحاضنة حزمة مراجعة اصطناعية، ثم الجسر نفسه ينشئ المرشح ويثبت ويربط؛ لا seed للمرشح أو الرابط. P2 الافتراضية بلا إسناد و P1 مستقلة؛ [تقرير P2](RAD-085_P2_SQL_REPORT_2026-10-26.md) و[تقرير P1](RAD-085_P1_SQL_REPORT_2026-10-26.md) أدلة تاريخية، والتكامل الجديد له دليله المحدد.
