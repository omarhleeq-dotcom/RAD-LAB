## ملخص الحالة
- **الاتجاه الحالي:** تأليف full-practical محلي مستقل من الحالات القائمة مع معاينة ضوابط وإسناد اصطناعي؛ P1 وmixed محفوظتان. كل SQL واختباراته الجديدة في جلسة أخيرة واحدة بعد تجهيز الواجهات.
- **ينتظر المالك:** تقييم P1/P2 والهاتف مؤجل إلى نهاية تجهيز الواجهات، وليس قبولًا أو اكتمالًا؛ لا تطلبه الآن. تبقى RAD-085 review دون اكتمال التأليف أو الإسناد أو صلاحيات المشرف الحقيقية. متبقي RAD-084/083/080/079/078 وDB day وRAD-077 وA/B/C1 محفوظ دون إعادة ترحيلات.
- **ينتظر مراجِعًا:** O108 والمصادر والرخص والمحاكي وMarker، وإنفاذ نطاق المشرف بالخادم. مشهد PracticalScene غير مضمن: يتجاوز حارس استيراد P2 بملفات رسم من مجلدات الحالات/الفحوص؛ يلزم فصل آمن مأذون دون تخفيف الحارس. RAD-019 مغلقة بدليلها دون مصادقة سريرية جديدة.
- **مرجع Git:** docs:context للحالة الراهنة؛ تقرير المتابعة للفحوص المنفذة وغير المنفذة وحدودها؛ لا CI أو نشر أو هاتف مفترض.
- **مخاطر معلنة:** المعاينة للضوابط فقط وتفصح عن غياب المشهد، ولا تعريض أو تصحيح. الحفظ والإسناد في ذاكرة fixture دون publication؛ الصلاحيات في العرض ليست عزلًا أمنيًا. الربط والموافقة والعامل والنسخ والقبول بوابات لاحقة.

## الخطوة التالية والعوائق
توقف بعد التسليم حتى توجيه المالك؛ لا طلب تقييم الآن. المراجعة المحلية عند وقتها: `node scripts/qa/rad-085-authoring-audit.mjs --serve`، ثم عنوان loopback المطبوع مع locale=ar أو locale=en. اختر مجموعة ثم إنشاء full-practical المستقل؛ المسودة الحالية واحدة لكل حساب/مجموعة، وإعادة تحميل الصفحة تمحو الذاكرة. اختبر المراجع والترتيب والضوابط والإسناد وصفحاته والتبديل والإلغاء والتعارض والسحب والانتهاء؛ لا مسار منتج أو hosted preview. تدقيق الضوابط بكل الفحوص: الأمر نفسه مع --practical دون --serve. P1 بأمرها المحفوظ في تقريرها.

قبل الربط: عقد آمن للمشهد، المراجعة المستقلة ومقياس النشر النهائي، ثم جلسة القاعدة المجمعة وقبول التفويض والتزامن والنسخ والعامل وصورة متطابقة مع الإصدارات. أسماء DTO/العمليات المحلية ليست schema أو RPCs نهائية. إن أُغلق PR أو دُمج فتوقف وأبلغ المالك قبل أي بديل؛ لاready/merge/auto-merge أوsubscribe/poll.
