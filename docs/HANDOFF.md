# التسليم الحالي — إصلاح الرسم وبداية تدريب نظيفة

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context` و`npm run status:summary -- --id RAD-058`. النطاق وقرار المالك في [S-MY-ATTEMPTS-1](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط)؛ أدلة هذه الدفعة وحدود فحوصها في المهمة ووصف المسودة فقط.

## المتبقي
حسم الاستثناء المحدد في `record-contracts.test.ts`: توقع المحاولة الناتجة من `evaluate` هوية التقييم بدل `unknown`؛ لا تغيير درجات أو توقع تاريخ مجهول. التوقع لم يُعدّل. حسم حد بصمة التعريف التي تشمل النصوص: إبقاؤها مع توثيق الحد، أو نطاق مستقل لهوية مقارنة تحفظ الأصل؛ لا تغيير خفي للخوارزمية. [عقد الإصدار وصيانته](PILOT_SUPABASE_SETUP.md#practice-evaluation-version) يوضح حدود الضمان اليدوي.

بعد ذلك مراجعة إصلاح الرسم والتحقق من مسار الخدمة وفق [إجراء النشر](PILOT_SUPABASE_SETUP.md#training-deployment-check)، وخاصة رفض اختيار مستخدم آخر للمشارك؛ إفادة المالك بعمل الحسابات والمحاولات والمتابعة لا تثبت هذا الفحص السلبي. إثبات التوافق لم يُسجّل؛ لا تعِد تطبيق ترحيل التدريب الذي أبلغ المالك نجاحه. الهاتف الفعلي للمالك.

التصفير اختياري وغير معتمد: يلزم تحديد جميع محاولات Practice أو حسابات محددة، ثم فحص catalogue الحي وعدّ المحاولات والملاحظات والأحداث المرتبطة واستعلامات معاينة محدودة ونسخة قابلة للاسترجاع. أصلح الكاتب وانشر الإصلاح المصرّح به وأوقف الكتابة أثناء التنظيف قبل اعتماد عملية حذف محددة؛ الملاحظات مرتبطة بحذف متتابع، والأحداث تربط المحاولة داخل JSON. أبقِ الحسابات والأسماء والأدوار والموافقات. لا اتصال إداري مباشر هنا؛ يجهّز الإجراء للمالك إذا لم يتوفر. لا حذف أو إعادة ختم للماضي، ولا اختبار نظافة حي قبل الاعتماد والتنفيذ الفعليين.

## الحدود والعوائق
حارس النشر يبقى فعالًا؛ نجاح SQL لا يضبط متغير GitHub، والفحوص المحلية ليست Auth/PostgREST أو عزلًا حيًا. غياب الإثبات يحجب البناء والرفع الجديدين؛ لا تستخدم تسجيله لتجاوز التحقق. عوائق Access وبقية تحقق المزوّد باقية في مهامها. لا معاينة مستضافة من الوكيل.

## المتابعة
RAD-058 تبقى للمراجعة مع وصفها ودليلها وجهة انتظارها معًا. المشرف وAssess وO106–O108 والفحوص والصور والتحسين البصري المستقل مؤجلة. التسليم Draft فقط؛ حقائق Git/PR تُقرأ بأدواتها، وبقية المهام في [الحالة](project-status.md).
