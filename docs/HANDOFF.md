# التسليم الحالي — إغلاق هوية المقارنة وتأجيل التصفير

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context -- --pr 88` و`npm run status:summary -- --id RAD-058`. الأدلة في المهمة ووصف المسودة فقط؛ [العقد](PILOT_SUPABASE_SETUP.md#practice-comparison-version) و[إجراء التجهيز](PILOT_SUPABASE_SETUP.md#practice-optional-reset).

## المكتمل
اكتمل مسار هوية المقارنة ودُمج PR #88. نجح CI ونشر `main`، ثم راجع المالك نسخة الإنتاج وأكد أن كل شيء يعمل. الأدلة التفصيلية وحدودها في RAD-058؛ لا تعِد SQL أو الخدمة أو تجربة المحاولات دون تغير ذي صلة. استثناءات الحارسين محفوظة بحدودها في [القرار](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط).

## المتبقي
لا عمل منتج متبقٍ في RAD-058. اختار المالك تأجيل حذف البيانات القديمة؛ لا حذف معتمد ولا حاجة إليه لعمل الرسم. عند استئناف التصفير اتبع [إجراء التجهيز](PILOT_SUPABASE_SETUP.md#practice-optional-reset) من catalogue وعدّ حي ونسخة مجرّبة ومنع كتابة ثم اعتماد حذف مستقل.

اختار المالك جميع محاولات Practice للمعاينة فقط؛ لا حذف معتمد. يشغل المسؤول فحص catalogue والعدّ والمعاينة محليًا على المشروع المطابق، ويحفظ المخرجات التفصيلية والنسخة خارج Git والمحادثة. يلزم عدّ المحاولات وfeedback والأحداث، ونسخة مجرّبة الاستعادة ومنع كتابة فعلي للنسخ القديمة قبل تجهيز واعتماد حذف محدد. لا SQL حذف قبل catalogue الحي، ولا درجات افتراضية لاختبار النظافة.

## الحدود والعوائق
لا اتصال إداري أو بيانات اعتماد مهيأة للوكيل؛ لا عدّ أو نسخة حية منفذة. الحسابات والأسماء والأدوار والموافقات محفوظة، والأحداث مقترح إبقاؤها بعد مراجعة أثرها. نجاح المسودة لا يحدّث main أو الروابط القديمة؛ التنظيف ليس علاج الرسم ولا شرط حفظ التاريخ.

حارس النشر بقي فعالًا وقبل الإثبات الجديد في نشر المسودة؛ لم يُنشر main ولم تتغير سياسات الإنتاج. الهاتف الفعلي اختبره المالك؛ لا فتح أو مشاركة معاينة مستضافة من الوكيل.

RAD-058 منتهية. يبدأ العمل التالي بمعرّف RAD-059 بعد تحديد نطاقه؛ لا تُنشئ مهمة لمجرد التصفير المؤجل. Assess والمشرف وO106–O108 والفحوص والصور مؤجلة. حقائق Git وCI تُقرأ بأدواتها ولا تنسخ هنا.
