# التسليم الحالي — RAD-085 / هوية الاتصال والإبطال المحليان

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، ثم docs:context وstatus:summary لـRAD-085؛ [project-status](project-status.md) وحده مصدر الحالة. تحقق مباشرة من#137: open/Draft/unmerged؛ إذا أُغلق أو دُمج فتوقف وأبلغ المالك قبل بديل. استمر في checkout نفسه دون worktree/subagents أو ready/merge/auto-merge. لا لابتوب/هاتف/Windows/WSL أو hosted preview مطلوب لهذا العمل المحلي.

## ملخص الحالة
- **الاتجاه الحالي:** [تقرير الاتصال](RAD-085_CONNECTION_IDENTITY_2026-10-26.md) يثبت محليًا LOGIN خدمة محدودًا منفصلًا عن المستخدم/المجموعة والدور الداخلي، وإبطال الجلسات وpool/cache والرد المتأخر ومصالحة ACK. لا SQL أو بصمات جديدة؛ [حزمة التطبيق](RAD-085_APPLICATION_PACKET_2026-10-26.md) لم تطبق حيًا.
- **ينتظر المالك:** إجراء محو واحتفاظ للروابط والمراجعات وسجل السحب، مخزن مراجعة حقيقي وسياسة مشاركة وقناة هوية وإبطال تشغيلية، ثم مراجعة P1/P2 والجسر والإسناد والإغلاق والهاتف. لا قبول نيابة عنه.
- **ينتظر مراجِعًا:** الأمن/ACL والتزامن والمحو والنسخ/restore للمزوّد والمحتوى والمصادر والرخص وO108 وMarker والحمل والتكلفة والقبول؛ لا مراجعة أمنية مستقلة أو إغلاق RAD-063/RAD-060 من اختبار محلي.
- **مرجع Git:** docs:context للرأس والحالة الفعلية، وتقرير الاتصال للمنفذ وحدوده ووصف PR لدليل CI وتخطي النشر على الرأس نفسه؛ لا نجاح رأس سابق أو نشر/هاتف مفترض.
- **مخاطر معلنة:** NOLOGIN لا يقطع المفتوح؛ سحب خارج القناة يتسلسل بالأقفال ولا يضمن إبطالًا فوريًا. بعدCOMMIT قد تبقى كتابة رغم حجب الرد؛ المصالحة قراءة صريحة. محو الروابط والمراجعات عائق تشغيلي باقٍ، وإبطال العرض لا يحلّه.

## الخطوة التالية
راجع التقرير والعقود والحزمة، ثم احسم إجراء الاحتفاظ/المحو ومسؤول replay للسحب بعدrestore، وقناة المصادقة والإبطال التشغيلية ومراجعاتها بإذن مستقل قبل أي وصل حقيقي. فقد قناة الإبطال يغلق المضيف وpool محليًا؛ التعافي بمضيف ومصادقة جديدين. لا تستعد cache أو capabilities أو credentials من لقطة قديمة، ولا تعاود mutation آليًا عند فقد ACK.

شواهد انتهاء الجسر بعد أقفال reference/advisory/version وحذف العضوية المتسلسل أصبحت اختبارCI مطلوبًا دون skip: تعيد الخلل على الرأس السابق المثبت وترفضه على المصحح. اختبار النسخ الكامل السابق مستقل ولم يُعد في جلسة الاتصال. [التدقيق السابق](RAD-085_SECURITY_AUDIT_2026-10-26.md) و[فرق استثنائه](RAD-085_SQL_AUDIT_PROPOSAL_2026-10-26.patch) محفوظان؛ الاستثناء المطبق ليس إذنًا دائمًا لتغيير SQL أو توقعات/بصمات أخرى.

متطلبات العامل التالية فقط: مطابقة worker/case/evaluator، والصورة، والهوية، وSTOP، والمراقبة، والتكلفة. لم يُشغل أو ينشر عامل أو scheduler أو تُنشأ هوية تشغيلية.
