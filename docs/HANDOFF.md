# التسليم الحالي — توافق قاعدة التدريب

## نقطة البداية
اتبع [AGENTS](../AGENTS.md) و[خريطة القراءة](README.md#read-by-task)، ثم `npm run docs:context` و`npm run status:summary -- --id RAD-058`. إذن المالك في [S-MY-ATTEMPTS-1](DECISIONS.md#s-my-attempts-1--استئناف-محاولاتي-فقط) يشمل إصلاح تشخيص غياب تحديث قاعدة التدريب ومنع نشر رابط غير متحقق منه.

## المتبقي
تأكيد مشروع Supabase الذي يستخدمه البناء، والتحقق من رد الخدمة الحي؛ التشخيص المحلي لا يجزم بالخطأ الحي من الصورة وحدها. الترحيل الإضافي للاسم والتدريب غير مطبّق ضمن هذا العمل. يلزم [مسار التحقق](PILOT_SUPABASE_SETUP.md#training-deployment-check): SQL للقراءة فقط، ومعالجة نقص الترحيل بإذن مناسب، والتحقق بحساب مشارك ومالك، ثم تسجيل إثبات التوافق وإعادة تشغيل النشر المصرّح به. بعده مراجعة المالك للتدفق واللغة والهاتف الفعلي. الأدلة في RAD-058 ووصف PR، دون تقرير أو قائمة منفصلة.

## الحدود والعوائق
حارس النشر يتحقق من إثبات يدوي مرتبط بالمشروع ومحتوى SQL، ولا يتصل بالقاعدة أو يكشف الانحراف الحي خارج Git. غياب الإثبات يحجب البناء والرفع الجديدين ويستبدل تعليق الرابط برسالة حجب؛ الروابط القديمة تبقى على نسختها. لا تغيير إعدادات مزوّد أو متغيرات GitHub أو قاعدة حية هنا. إذا كانت قاعدة المعاينة مشتركة مع الإنتاج فالتطبيق عليها يحتاج إذن إنتاج صريحًا. عوائق Access وبقية تحقق المزوّد باقية في مهامها.

## المتابعة
RAD-058 تبقى للمراجعة مع وصفها ودليلها وجهة انتظارها معًا. المشرف وAssess وO106–O108 والفحوص والصور والتحسين البصري المستقل مؤجلة. التسليم Draft فقط؛ حقائق Git/PR تُقرأ بأدواتها، وبقية المهام في [الحالة](project-status.md).
