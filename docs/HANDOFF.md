## ملخص الحالة

- **الاتجاه الحالي:** أفاد المالك بنجاح P1 الحي؛ A مدموج وB يضيف الرموز القصيرة والأسماء ضمن الفلاتر القائمة. [تقرير B](RAD-085_P1_USABILITY_B_2026-10-28.md) يحفظ الميزانية وأسباب تعديل الاختبارات وpins وQA؛ [قرار A/B](DECISIONS.md#rad085-p1-usability-owner-2026-10-28) يحدد الإذن.
- **ينتظر المالك:** مراجعة B ثم [mini DB day](RAD-085_P1_B_DB_DAY.md)، والجاهزية والدخان قبل ضبط العلامة المذكورة فيه. تدوير الرموز القائمة لازم؛ تأكيد حذف النسخ وإفراغ المهملات وفق الإجراء السابق.
- **ينتظر مراجِعًا:** تطبيع الرمز وentropy/throttle، ثبات الرؤية، أسماء الحسابات القديمة، الحزمة المولدة والتراجع؛ تبقى مراجعات الأمن/ACL والحقوق والمزوّد والقبول وخصوصية Auth بلا FK.
- **مرجع Git:** docs:context للحالة الحالية، ووصف Draft والتقرير لدليل CI/Pages وQA. لا فتح أو مشاركة روابط معاينة مستضافة.
- **مخاطر معلنة:** frontend B يحتاج migration B قبل علامته؛ التراجع يحتاج واجهة/علامة A وتدوير الرموز. [قاعدة الهاتف](DECISIONS.md#rad085-mobile-sql-owner-2026-10-28) مستمرة ورافعها RAD-082؛ RAD-059/RAD-082 قبل أول امتحان حقيقي.

## الخطوة التالية والحدود

راجع التقرير ثم دليل mini DB day وحزمته: لا تعِد DB day السابق أو المُهيّئ ولا تغيّر بايتات الترحيلات المطبقة. المولّد يعمل على PostgreSQL محلي معزول فقط، واختباراته ضمن CI. يجمع المالك أجزاء كل معاملة كاملة قبل تنفيذها؛ لا تنفيذ جزء أو commit مبكرًا. الانجراف المجهول يوقف الحزمة ولا يُقبل بتغيير pins.

لا qa:golden/qa:characterise أو SQL حي من الوكيل أو Variables أو نشر يدوي أو ready/merge/auto-merge. مسارا GitHub المعتادان يعملان دون skip ci؛ لا subscribe/poll. نجاح PostgreSQL المحلي لا يثبت تنفيذًا حيًا أو هاتف المالك.
