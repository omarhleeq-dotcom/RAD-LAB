# التسليم الحالي — RAD-085 / المشاركة وقرارات المالك

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، وشغّل docs:context وstatus:summary لـRAD-085؛ [project-status](project-status.md) وحده مصدر الحالة. تحقق مباشرة من#137 open/Draft/unmerged؛ إن أُغلق/دُمج فتوقف وأبلغ المالك قبل بديل. تابع checkout نفسه دون worktree/subagents أو ready/merge/auto-merge.

## ملخص الحالة
- **الاتجاه الحالي:** [تقرير المشاركة](RAD-085_SHARING_OWNER_REPORT_2026-10-26.md) يحفظ النصAR/EN وربطه بنسخة/بصمة وقبول الذات والسحب محليًا عبرRPC القائمة. [قرارات المالك](DECISIONS.md#rad085-owner-final-local-2026-10-26) حاكمة؛ لا إعادة سؤالها. أضيف ملف تهيئة SQL المحلي مطابقًا للمقترح بعد الاستثناء المحدد، واختُبر دون إنشاء موافقات أو تطبيق حي.
- **ينتظر المالك:** أدلة إسناد/رخص المحتوى اللازم وحقوله قبل فرق نقل إدارة الكاتب وإزالة هويته. أصل الحفظ ونقل الإدارة محسوم؛ لا نسبة تأليف للمالك أو نقل شامل. قبول P1/P2 والجسر والإسناد والإغلاق/الهاتف باقٍ.
- **ينتظر مراجِعًا:** الأمن/ACL/التزامن والمحو/المزوّد والمحتوى/المصادر/الرخص/O108 وMarker والقبول؛ لا مراجعة مستقلة أو إغلاقRAD-063 من التجربة. لا تكلفة متوقعة تُفعّل قبل عرضها على المالك.
- **مرجع Git:** docs:context للرأس والحالة الفعلية، وتقرير المشاركة للتحقق وحدوده؛ تحققCI وتخطي النشر على آخر رأس نفسه، لا نجاح رأس سابق أو نشر/هاتف مفترض.
- **مخاطر معلنة:** نقل الكاتب المشترك غير منفذ؛ حراس الإغلاق والمجموعة وprovenance لا تتجاوز. policy التشغيلية غير مهيأة. [قائمة التشغيل الموحدة](RAD-085_REMAINING_OPERATIONS_2026-10-26.md) تميز التاريخي/المحلي/المزوّد؛ permit صناعية والعامل محلي لا تشغيل عام.

## الخطوة التالية
راجع [الملحق المحلي](../supabase/manual/rad085-sharing-policy-local.sql) و[التقرير](RAD-085_SHARING_OWNER_REPORT_2026-10-26.md#7-البوابات-والاستثناء-المعتمد): الاستثناء **RAD085-SQL-SHARING-POLICY-LOCAL-20261026** معتمد ومنفذ بايتًا للمقترح، دون تهيئة حية أو قبول نيابة عن شخص أو تغيير الموافقة العامة/الشهادات. لا تكرره أو تعممه؛ انتقل إلى عوائق الكاتب والمراجعات وإعدادات التشغيل في القائمة الموحدة، دون استنتاج إذن خارجي.

راجع [حالات الكاتب](RAD-085_ERASURE_MATRIX_2026-10-26.md#أثر-قرار-المالك-الأحدث-وحالات-الكاتب-المحجوبة): الخاص غير المتعارض يمحى بالقائم، والمشترك/المغلق يحفظ مع بقاء التعطيل حتى تحديد الحقول والحقوق وفرقSQL مستقل واستثناء جديد. لا تعطيلtrigger أو CASCADE شامل أو تجاوز30يومًا/حمايةالنفس/آخرمالك. احفظ نتائج الآخرين ونسخهم وإغلاقهم النهائي.

المالك مسؤول الإدارة والتشغيل حاليًا؛ حساب الإنسان منفصل عن هوية الخدمة، وإضافة مسؤولين لاحقًا بحساباتهم دون أسرار مشتركة أو نظام أدوار جديد الآن. بريد الموقع للتشغيل والمراسلات، والبريد الشخصي لطلبات الحساب؛ وصول البريد ليس تفويض موافقة. Brevo قائم بدليل تاريخي؛ صلاحية ربطه تحتاج تحققًا لاحقًا لا مزوّدًا ثانيًا.

النسخ والاستعادة وتجهيز Docker المحلي مؤجلة **بالكامل للجلسة الأخيرة المخصصة لها**؛ لا تطوير أو مقارنة تخزين أو نسخ سحابية الآن، ولا ادعاء إنجاز. مخزن دليل المصالحة السحابي لم يُحسم؛ الاعتماد المعماري ليس إذن إنشاء. احتفظ بمتطلبات حداثة head وقنواته/سلامته وإبطاله للجلسة المناسبة دون تعطيل المحلي المستقل.

بعد restore تبقى API والنقل والقراءات والعامل محجورة حتى أحدث الحذف والسحب/التعطيل/الإغلاق والصيانة وإبطال الجلسات والقدرات والأسرار وpool/cache والتحقق من اكتمالها. [إجراء التعافي](RAD-085_ERASURE_RECOVERY_2026-10-26.md) و[الهوية](RAD-085_CONNECTION_IDENTITY_2026-10-26.md) يحفظان الحراس؛ launch_gate وحدها ليست حجرًا. لا تستعد credentials قديمة ولا mutation آلية عند ACK مفقود.
