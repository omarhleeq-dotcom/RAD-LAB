- **ينتظر مراجِعًا:** الأمن/ACL/التزامن والمحو والحقوق/المصادر/الرخص وO108 والمزوّد والقبول. نجاح محلي لا يغلق RAD-063 أو يثبت الهاتف أو خدمة حية.
- **مرجع Git:** docs:context لحالة الفرع وPR؛ التقرير ووصف PR لدليل QA وCI للرأس نفسه، دون نجاح أو نشر مفترض من دمج سابق.
- **مخاطر معلنة:** [D3](RAD-085_D3_SQL_GAP.md) غير منفذ؛ لا تعيين مشرف حقيقي قبل دمج إصلاح نقل الإدارة والمحو ضمن30يومًا. RAD-082 اليومية الآلية وRAD-059 الذي يوقف الإنفاق شرطان قبل أول امتحان حقيقي.
