## ملخص الحالة
- **الاتجاه الحالي:** SQL المحلي المجمّع مأذون؛ توقف قبل أي migration أو اختبار قاعدة جديد عند توقع قائم. [تقرير العائق](RAD-085_SQL_BLOCKER_REPORT_2026-10-26.md) يشرح الدليل والاستثناء المحدد المقترح؛ [الخطة](RAD-085_PLAN_2026-10-25.md) تحفظ النطاق.
- **ينتظر المالك:** استثناء مسمى لتوقع deferredMigrations الفارغ؛ مراجعة P1/P2 والهاتف أُجلت إلى ما بعد SQL والربط الفعلي ونسخة متصفح قابلة للمراجعة. لم تحصل المراجعة أو الموافقة، ولا إذن تشغيل حي.
- **ينتظر مراجِعًا:** التفويض والتزامن والموافقة والنسخ/restore والعامل المتطابق والمقياس وO108 والمصادر والرخص والمحاكي وMarker والقبول؛ لا publication أو مراجعة مخترعة.
- **مرجع Git:** docs:context للحالة الراهنة؛ تقرير العائق للتحقق المنفذ وغير المنفذ. تقارير الواجهات أدلة تاريخية، لا CI أو نشر أو هاتف مفترض.
- **مخاطر معلنة:** العرض والحفظ والإسناد في ذاكرة اصطناعية؛ لا ربط أو إنفاذ خادمي. لم تتغير RAD-060 أو المهام الأخرى؛ نجاح SQL مستقبلًا لا يغلق الربط أو التشغيل.

## الخطوة التالية والعوائق
راجع الاستثناء المحدد في التقرير قبل استكمال SQL؛ لا تغير التوقع أو الحارس دون الإذن المسمى المطلوب في أمر المالك. بعد رفعه: أكمل الجرد التفصيلي للمراجع والترحيلات وحراس الجاهزية والشهادة، ثم أعلن هدفًا وميزانية دقيقة تشمل migrations والاختبارات والعقود والتوثيق وأي وحدة مشتركة. أعد استخدام groups/memberships/assignments/close_assignment_v1، وأعلن أي تعديل لدالة أو constraint أو trigger قائم وسببه.

اختبر محليًا ببيانات اصطناعية؛ PostgreSQL معزول متعدد الاتصالات مطلوب للتزامن، ولا يكفي PGlite المتسلسل. لا ترحيلات جديدة حاليًا، وبالتالي لا قائمة تطبيق أو ترتيب جديد منفذ. جهّز قائمة الترحيلات ومتطلبات التطبيق اللاحق عند تنفيذها دون تطبيق حي.
