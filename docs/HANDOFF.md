# التسليم الحالي — سياسة Assess المعتمدة وربطها اللاحق

## نقطة البداية
اقرأ [AGENTS](../AGENTS.md)، وشغّل `npm run docs:context` مع تحقق GitHub لـ#95 و#96 وأحدث main وCI/Pages على رأسه نفسه، ثم `npm run status:summary -- --id RAD-056`. [project-status](project-status.md) المصدر الوحيد للحالة. حافظ على checkout المعزول والعمل القائم؛ التاريخ ليس أمر إعادة تطبيق أو QA.

## الهدف والمنجز
F مدموجة وأدلتها ونجاح CI/Pages لرأس الحزمة المحلي السابق وإفادة الهاتف العامة محفوظة في [التقرير](ASSESS_LOCAL_OPERATIONS_REPORT_2026-10-20.md). المسودتان غير مدموجتين عند التحقق الأخير. حزمة التشغيل المحلية واختبارات lease/failure/recovery والحذف والتوقف قائمة، بلا runtime منشور. اعتمد المالك الآن [S-ASSESS-15](DECISIONS.md#assess-retention-owner-2026-10-20) للخيارات الخمسة؛ [السياسة ونص EN/AR وخطة الربط](ASSESS_RETENTION_POLICY.md) تميز المعتمد عن غير المنفذ. النص المنشور v1 لم يتغير، وv2 محجوز للربط الصريح لا قبولًا قائمًا.

## الخطوة التالية
حزمة إنفاذ محلية بميزانية مستقلة: إغلاق نهائي للإسناد ومنع إعادة فتحه، وتعطيل Assess عن البدء الجديد دون تغيير Practice، وموافقة جديدة صريحة، وحذف metadata بشروطها عبر صيانة C؛ ثم تجربة نسخ/تصدير/restore اصطناعية قبل العمل الخارجي. لا تعِد طلب الخيارات المعتمدة أو قرارات الستة أشهر والحقول الأربعة وسياسة العلامة والمسارين. لا SQL أصلية أو نشر runtime/عامل/schedule أو تغيير PILOT_SCHEMA_VERIFIED/pins أو ready/merge أو فتح launch_gate. فحوص كل دفعة وحدودها في التقرير.

## المتبقي وحدود الأدلة
O106 المتبقي إنفاذ السياسة وتجربتها والتحقق من نسخ المزود، لا اختيار المدد المعتمدة مجددًا. غير المؤقت خارج التجربة الأولى ومحجوب؛ لم تُحدد مدة متروكه لكل المستقبل. النسخ التي نديرها يومية مشفرة بتداول سبعة أيام؛ لا وعد مماثل للمزود أو ادعاء نسخة موجودة. بعد restore يبقى الوصول مغلقًا حتى إعادة الحذف والصلاحيات، بما يمنع إحياء موافقة/إسناد أو metadata حذفت بعد snapshot. O108 والمصادر والترخيص والمراجعة والخلفية والمعايير وMarker، وruntime والعامل والجدولة والمراقبة والنشر والاسترداد بوابات مستقلة؛ القبول التجريبي الحي غير مكتمل.

## التدريب والأدلة السابقة
Practice وسلوكه ودرجاته وصوره وبياناته وتوقعاته وبصماته محفوظة.
