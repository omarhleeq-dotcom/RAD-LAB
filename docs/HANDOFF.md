## ملخص الحالة
- **الاتجاه الحالي:** P1 ثم حفظ مسودات P2 واسترجاعها وتعديلها عبر RPCs القائمة وPostgreSQL معزول، مع فصل mixed/full-practical واستعادة تعارض revision وACK دون retry آلي. [تقرير P2](RAD-085_P2_SQL_REPORT_2026-10-26.md) للتحقق وحدوده، و[تقرير P1](RAD-085_P1_SQL_REPORT_2026-10-26.md) للأدلة السابقة؛ [العقود](RAD-085_SQL_CONTRACTS_2026-10-26.md) للمطابقة وحدود الإبطال.
- **ينتظر المالك:** مراجعة P1/P2 والهاتف بعد تجهيز النسخة المحلية. قبول المتصفح الآلي ومحاكاة390لا يحلان محل المراجعة على هاتف حقيقي، ولا موافقة مشاركة أو إذن حي.
- **ينتظر مراجِعًا:** التفويض والتزامن والمشاركة المعتمدة والنسخ/restore والأداء والمصادر والرخص وO108 والقبول. RAD-060 وإغلاق الإسناد محفوظان خارج الدفعة.
- **مرجع Git:** docs:context للحالة الراهنة، والتقرير للتحقق المحلي ووصف PR لدليل CI على آخر رأس ومنع النشر؛ لا نجاح رأس سابق أو نشر أو هاتف مفترض.
- **مخاطر معلنة:** سياسة المشاركة وسجل المراجع التشغيلي والجسر غير مهيأة؛ إبطال SSE محلي فقط وليس إشعارات Supabase. النسخة المحتفظ بها للتعارض في ذاكرة الجلسة فقط وتُمسح بفقد النطاق؛ القفل العالمي والسعة يحتاجان قياسًا.

## الخطوة التالية وإعادة المراجعة
مراجعة المالك P1/P2 والهاتف مستقلة، ثم توجيه جديد قبل أي توسع. لا استنتاج اكتمال النشر أو الإسناد أو إذن التطبيق الحي من نجاح المحلي أو CI. تقارير الواجهات وSQL السابقة محفوظة تاريخيًا، وأمر المالك الحالي يحكم تسلسل العمل.

من جذر المشروع: npm ci --ignore-scripts ثم node scripts/assess/setup-rad085-postgres.mjs. للمراجعة التفاعلية شغّل node scripts/qa/rad-085-p2-sql-audit.mjs --serve؛ اختر locale=ar أو locale=en من عنوانloopback المطبوع. يحفظ PostgreSQL المسودات عبر إعادة تحميل المتصفح حتى إيقاف الحاضنة؛ Ctrl-C يحذف قاعدة الاختبار المعزولة. --unconfigured يثبت رفض مراجع غير مهيأة. لا بيانات حقيقية أو سياسة/ترخيص/اعتماد طبي مخترع.

P1 متاح بالحاضنة القائمة node scripts/qa/rad-085-p1-sql-audit.mjs --serve؛ --unconfigured يبقي الانضمام مغلقًا بلا سياسة. الحاضنتان مستقلتان ببيانات اصطناعية، ولا تمثلان auth أو Realtime حيًا. أوامر الاختبار وأدوات المتصفح في تقرير P2؛ لا hosted preview أو مشاركة روابط مستضافة.
