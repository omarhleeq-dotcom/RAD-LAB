# التسليم الحالي — RAD-062 P9، يوم CLI محجوب

اقرأ [AGENTS](../AGENTS.md)، ثم docs:context وstatus:summary للمهام RAD-062 وRAD-086 وRAD-059؛ استمر في checkout نفسه. [الحالة](project-status.md) المصدر الوحيد للمهام.

## ملخص الحالة

- **الاتجاه الحالي:** RAD-062 in_progress/reviewer؛ P8 مدموجة خاملة في #172 بتحقق GitHub. P9 دليل اللابتوب وأدواته في Draft للمراجعة وفق [التقرير](RAD-062_P09_REPORT_2026-10-30.md) و[الدليل](RAD-062_P09_LAPTOP_RUNBOOK.md). يوم القاعدة محجوب على عوائق الاستعادة والفحوص قبل P10. بقايا Part A في RAD-057 وRAD-087 وفحص SID100 محفوظة في الحالة.
- **ينتظر المالك:** RAD-086 حتى اللابتوب والنسخ اليومية المحلية وسجل المصالحة المشفر واستعادة مجربة ورفض اعتماد Supavisor القديم/cache؛ نسخة كاملة متحقق منها قبل يوم CLI. قبول4أ وRAD-060 وفجوة الإغلاق الحي و[متابعته](RAD-060_PHASE1_FOLLOWUP_2026-10-29.md)، وRAD-059 القنوات واختبار الاستلام والبديل وحذف CSV وإفراغ المهملات؛ RAD-087 فحص الحوض والكتف عند SID100.
- **ينتظر مراجِعًا:** عائق تمثيل ACL بعد restore وتعارض فحص B المطلوب ذي catalogue ثابت مع إضافات RAD-062؛ لا إعفاء أو تغيير توقع في P9. RAD-032 للأشعة وRAD-056 عبر RAD-063 وRAD-041 عزل الإنتاج؛ عقود الحزمة والتنافس والطوارئ والحقوق/D3 والأمن والخصوصية وAuth بلا FK، ولا مشرفين حقيقيين قبل O4.
- **مرجع Git:** docs:context لحالة الفرع وPR؛ [تقرير P9](RAD-062_P09_REPORT_2026-10-30.md) للفحوص المنفذة وغير المنفذة والميزانية وحدودها. CI وDeploy Pages المعتادان مأذونان؛ Draft فقط بلا skip ci أو نشر إضافي أو معاينة مستضافة أو polling.
- **مخاطر معلنة:** gate مغلقة والعامل NOLOGIN والسر DISABLED. نجاح QA لكشف STOP ليس نجاح يوم القاعدة. طوارئ v2 والتحقق وdry-run تبقى هاتفية وحاجبة؛ أمر المالك يطلب التمرين بعد اكتمال التركيب وقبل P10 مع بقاء الخمول، باستثناء ضيق من توقيت packet دون تغيير بايتاتها. لا تشغيل كتابي للناس أو إغلاق شروط أول امتحان من دمج backend.

## المتابعة

بروفة Docker worker المحلية بقيت STOP بسبب سعة overlay/vfs، مع نجاح check/build وبقية الفحوص؛ يلزم تشغيلها بسعة كافية قبل القبول، دون تغيير CI أو اختبار لإخفاء الفشل.

راجع عوائق [تقرير P9](RAD-062_P09_REPORT_2026-10-30.md) أولًا؛ لا تصل إلى apply الحي حتى تفسير catalogue/ACL ونجاح كل required check والجاهزية على استعادة المالك وبروفة PostgreSQL17.11. لا تغيّر بايتات أو تصنيف required/checks أو marker في P9. كلا packetين ثابت، RAD062_AVAILABLE=false وP1_AVAILABLE=true؛ لا M1–M4/B أو initializer replay.

يوم CLI واحد فقط بعد RAD-086 واللابتوب والنسخة الكاملة المتحقق منها ومسار CLI المراجع؛ أي فشل يوقف اليوم. عند ACK ملتبس لا تعاود التطبيق أعمى؛ استخدم ledger والتحقق المستقل وخطة forward-fix المراجعة. P10 وحدها بعد الدليل الكامل وطوارئ الهاتف لترقية required/checks/guards وحساب marker الحقيقي، يضعه المالك.4ب/5ب والصور والقرب وManage targets والمتابعات المستقلة خارج الدفعة.
