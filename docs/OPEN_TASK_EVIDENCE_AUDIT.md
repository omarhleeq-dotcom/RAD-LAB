## 4. المشترك وScale

لا أداة جديدة أو حقل JSON أو سجل حالة مكرر. التقرير لقطة جرد؛ الأوصاف والجهات في الحالة هي موضع المتبقي الحالي. تُصحح خارطة الطريق النشطة بدل إضافة طبقة «أحدث» فوق عبارة #82 غير المدموج. تتبع source_ref يستخدم الأصل المؤرشف عند الإحالة إلى G0/تقرير .3، لا عناوين حُذفت من الملف النشط.

Scale: لا حد منتج جديد، ولا قوائم ثابتة في الكود. الجرد يغطي المجموعة المستخرجة من الحالة عند البداية؛ المهمة الجديدة لاحقًا لا يلزم إضافتها إلى هذه اللقطة التاريخية بل إلى الحالة مع دليلها. التحقق الشبكي محدود بقراءات PR/run/jobs محددة دون بحث عن أسرار أو إعدادات حساب أو polling. قائمة التحقق أدناه تجمع الأعمال المتداخلة مرة واحدة دون دمج نطاقاتها.
