# RAD-085 — استكمال SQL المحلي واختبار المخطط الموسّع

## 1. الانحرافات والميزانية

الهدف الواحد: استكمال تحقق SQL المحلي للمشرف وP1/P2، وحفظ حدود fixtures التاريخية، وتجهيز PostgreSQL في CI مع check ناجح. الميزانية الأولية24ملفًا، عُدلت علنًا إلى26 لإضافة ملفَي اعتماد PostgreSQL المقفولين. استُخدم24ملفًا من26؛ لم تُعدّل ترحيلتا المسودات والإسناد المحجوزتان للإصلاح.

الأسماء المحجوزة: اختبارات deployment الأربعة assess-d-schema وassess-e-schema وowner-dashboard-deferred-schema وfrontend-schema؛ اختبارات assess الأربعة retention-install وserver-trial-catalog-diff وserver-trial-reviewed وstaging-catalogue؛ pilot/db-day-wiring؛ assess/server-rad085-contracts وrad085-db؛ scripts/assess/local-database.mjs وtrial-install-rehearsal.mjs وsetup-rad085-postgres.mjs وpostgres-test/package.json وpackage-lock.json؛ .github/workflows/ci.yml؛ scripts/pages/frontend-schema.json؛ ترحيلات RAD-085 الثلاثة؛ الخطة والحالة وHANDOFF وعقود SQL وهذا التقرير. كل أسماء الاختبارات تنتهي .test.ts وتحت src/features. لم تتغير ترحيلتا المسودات والإسناد.

الإذن الحالي يجيز الاستثناءات المسماة في§7 من [تقرير df8fc5a](RAD-085_SQL_REPORT_2026-10-26.md)، ويشترط حفظ البصمات والتوقعات الأمنية ورفض الجديد غير المصنف، وإثبات رفض أدوات الجرد القديمة للمخطط الموسّع. لا استثناء ضمني لتوقع آخر أو بوابة تشغيل. نفس checkout وفرع #137 المفتوح Draft، دون worktree/subagents أو PR جديد؛ main والرأس جُلبا وتحققت حالتهما قبل العمل.

## 2. المنجز والمستبعد

استُبدلت توقعات القائمة الفارغة في D/E/C1-C2 بتحقق مساواة صريح للترحيلات الثلاثة وأسماء ملفاتها وبصمات SHA-256 وسبب التأجيل وحدود الخادم. لا مسار يقبل migration غير مصنف؛ حارس pilot-schema-gate لم يتغير.

fixtures التاريخية تستبعد أسماء RAD-085 الثلاثة بالضبط، دون فلتر تاريخ أو prefix يخفي المستقبل. local-database يدعم through=pre-rad085 الصريح؛ latest ما زال يطبق السلسلة كاملة. مداخل التجربة المحددة وrehearsal التثبيت التاريخي تطلب النطاق التاريخي صراحة. retained B يحذف الملفات الثلاثة من نسخته المؤقتة، ومقارنة دوال retention تبقي المتوقع36 وكل بصمات الحزمة الأصلية. جرد staging وشروط trial وDB day وشهادات التطبيق لم تتغير.

اختبار مستقل يطبق المخطط الموسع كاملًا على PostgreSQL ويختبر التوافق القديم: الملكية وإدارة المجموعة/العضوية القديمة والتصفح والإغلاق، ورفض الجرد القديم للمخطط الجديد. اختبار PGlite منفصل للشهادة يثبت نجاح preinstall التاريخي على مدخله القديم ثم رفضه بـ55000 بعد إضافة الثلاثة؛ لا يدعي هذا إثبات التزامن. الاختبارات السابقة لحارس المصدر تستمر في رفض مجهول/غير مصنف وانحراف المصدر/ACL.

أضيفت تغطية رؤية نتائج المشرف: hidden لا يعيد أرقامًا، shown يعيد الكسور المحفوظة دون تغيير درجات، قبل العد والتصفح؛ منع مشرف آخر والطالب وanon/worker والمعلق، وحدود بدء المحاولة والانتهاء والمغادرة وإعادة الانضمام والسحب. أضيف تغير availability/reference revision/draft revision/policy/account status، وإنهاء المجموعة وتغير جيل التعيين، والانتهاء بعد انتظار قفل حقيقي. فشل مصطنع في INSERT targets يثبت rollback للإسناد وإيصال المراجعة ثم نجاح إعادة نفس الطلب بعد إزالة fault. حذف الطالب في PostgreSQL يزيل العضوية والمستهدفين والفترات ذات الصلة؛ حذف إسناد مغلق يرفض وفق الحارس القديم دون تجاوز الاحتفاظ.

## 3. حسب المهمة

RAD-085 تبقى review، دون completion_evidence أو ادعاء اكتمال الربط/التشغيل. عائق الاستثناءات المسماة رُفع بقرار المالك وعولج في نطاقه. RAD-060 تبقى review/code للزر والربط؛ سطح SQL وإغلاق الجهة المصدرة وclosed_at مثبتة محليًا، لا تطبيق قاعدة أو قبول متصفح/هاتف. بقية المهام محفوظة.

## 4. المشترك وScale والإصلاح

الوحدة المشتركة server-rad085-contracts أضافت دالة ترشيح تاريخي تستبعد الأسماء الثلاثة فقط؛ لا اختيار actor أو نقل حي. scripts/assess/local-database يضيف نمط تجهيز تاريخيًا صريحًا ولا يغير latest أو محدد اتصال. CI يشغل setup-rad085-postgres كخطوة واجبة قبل الاختبارات؛ الاعتمادان @embedded-postgres/linux-x64@18.4.0-beta.17 وpg@8.23.1 ومتعَدياتهما مثبتة بpackage-lock مستقل، ويستعمل npm ci في /tmp. يجهز symlinks لمكتبات ICU/libpq المرفقة، دون تعديل النظام أو URL/سر/متغير قاعدة. غياب الاعتماد أو فشل التشغيل يفشل الاختبارات؛ لا skip أو رفع مهل.

الخلل التنفيذي المثبت بالاختبار: appointment_v1 كان يرفض سحب تعيين حساب معلّق. عُدل تعريفه داخل migration RAD-085 المحلية غير المطبقة ليقصر شرط participant/approved على التعيين فقط؛ السحب لمالك approved من profile قائم. لم تتغير دالة تاريخية مطبقة أو constraint أو trigger قديم؛ لا صلاحيات owner للمشرف. حُدثت بصمة هذا المصدر المؤجل وحده في manifest، دون تغيير requiredMigrations/checks أو شهادة.

السقوف والقفل والاحتفاظ كما في [العقود](RAD-085_SQL_CONTRACTS_2026-10-26.md): صفحة20/max100،1000عضو،5مسودات و100revision و128KiB، وقفل نطاق يسلسل التغييرات وREAD COMMITTED. لا قياس120متزامنًا أو ضمانFREE؛ الأداء والسعة وتنظيف النسخ/الإيصالات وخطة restore بوابات قبول لاحقة. لا رفع حدود أو زمن لتجاوز فشل.
