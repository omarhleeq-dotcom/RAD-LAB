# Source register (S10-4)

**Status:** created in Session 10b (docs only). One row per source used or still needed by the exam references. Per-source notes (`<id>.md`) hold paraphrased claims with locators. **PDFs are never committed**; future sessions read the notes, not the PDFs. Rules: [`../DECISIONS.md`](../DECISIONS.md) S10-2 … S10-5; template [`../templates/EXAM_REFERENCE_TEMPLATE.md`](../templates/EXAM_REFERENCE_TEMPLATE.md).

**Provenance (all rows in §1):** Claims recorded from the owner's advisor reading (full text read by the advisor; not re-verified against the originals by Claude Code); locators to be spot-checked during educator/physicist review (O5). For the two ACR parameters the claims were supplied by the owner in the Session 10b follow-up prompt and Claude Code did not fetch the documents.

**Governing authority (S10b-25, owner decision 2026-10-06, final, binding):** **BONTRAGER-9 is the governing authority for X-ray positioning and technique.** Other sources are supporting. On any conflict Bontrager wins; where it is silent use the next official source (EC16260, ACR-CHEST / ACR-PORTABLE, WHO-TECH, WHO-CHEST), then owner decision. Textbooks may be used as sources (S10-5 as amended): facts paraphrased and cited by printed page, no text or figures reused (S10-3); third-party student notes are never cited.

**Commercial use (S10-3):** RAD-LAB is a commercial product. "Cite / paraphrase facts only" = facts are paraphrased with a locator; no text, table or figure is reproduced. Radiopaedia is not used. Textbooks: see the governing-authority rule above.
