Per-source notes (`<id>.md`) hold paraphrased claims with locators. **PDFs are never committed**; future sessions read the notes, not the PDFs. Rules: [`../DECISIONS.md`](../DECISIONS.md) S10-2 … S10-5; template [`../templates/EXAM_REFERENCE_TEMPLATE.md`](../templates/EXAM_REFERENCE_TEMPLATE.md).
