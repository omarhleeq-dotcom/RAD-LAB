## 8. قائمة المالك ونقطة الاستئناف

راجع diff الترحيل وعقود الخدمة وفصل موافقة البدء عن السجل/الاستكمال وشواهد الترقية والتزامن. الخطوة التالية تجهيز إجراء استعادة مع دليل أثر مستقل وتجربته على قاعدة اصطناعية معزولة، والتحقق من المزود؛ أي تطبيق مزود يحتاج نطاقًا وإذنًا مستقلين وترحيلًا إضافيًا فقط وشروط بداية/نسخة حديثة مناسبة. لا تتبع تعليمات marker F التاريخية لهذا العقد، ولا تغيّر PILOT_SCHEMA_VERIFIED لتجاوز منع النشر الحالي.

الاستئناف: اقرأ AGENTS وHANDOFF وproject-status وهذا التقرير والسياسة والدليل، ثم docs:context وRAD-056 وتحقق GitHub لـ#95 و#96 وأحدث main وفحوص الرؤوس المقصودة. احفظ العمل القائم ولا تنشئ worktree/subagents أو تعِد فحوص/SQL حية دون حاجة وإذن. أبق المسودة والبوابة كما هما؛ لا ready/merge/auto-merge أو إعلان قبول حي.
