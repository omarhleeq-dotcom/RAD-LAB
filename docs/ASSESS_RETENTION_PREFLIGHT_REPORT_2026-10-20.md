## 2. المنجز والمستبعد

أضيف فحص مستقل للقراءة فقط، بعقد `assess-retention-preinstall/1`. يعيد استعمال baseline ما بعد تثبيت F المراجعة من الحزمة التاريخية: جرد B–F والصلاحيات ومنح الأعمدة، وبصمات مصادر الدوال الـ32 بنسختي LF/CRLF المحددتين، وأشكال الأعمدة/القيود/الفهارس وtrigger موافقة F، وبوابة مغلقة. أضيف كشف غياب إضافة الاحتفاظ: جدول account_stops وclosed_at ودوال/فهارس/trigger الإضافة؛ وجودها كاملًا أو جزئيًا يمنع اعتبار القاعدة F غير معدلة.

المخرجات contract ومؤشرات boolean فقط؛ لا صفوف طلاب أو أجوبة/إعدادات/علامات أو bodies أو credentials. المعاملة READ ONLY وتنتهي rollback، بلا DDL أو DML أو RPC تشغيل أو استدعاء maintenance. يقرأ بيانات launch_gate فقط بالإضافة إلى catalogues؛ لا يغير قيمتها. اختيار مشروع SQL Editor يدوي؛ لا يدعي الفحص إثبات هوية المشروع.

`baseline_matches=true` تعني تطابق الحالة التشخيصية مع F المتوقعة وغياب الإضافة، **ولا تصرح بالتطبيق**. apply_authorized=false وmanual_review_required=true دائمًا؛ backup_verified وrecovery_verified وprovider_backups_verified وruntime_or_launch_verified كلها false لأن الاستعلام لا يثبتها. أي error/false/حالة جزئية يتوقف عند التشخيص، دون DROP أو إعادة ترحيلات أو normalization لبصمات غير متطابقة.

لم تُجهز حزمة كتابة على الأصلية في هذه الدفعة. لا تطبيق للترحيل الخام أو إعادة B/C/D/E/F؛ لا تمرير marker جديد أو تغيير pins/Variables. المتابعة تتوقف الآن عند النتيجة اليدوية المقروءة قبل اختيار أي إجراء كتابة وتجهيز نسخة ما قبل التغيير ومتطلبات الاسترداد ذات الصلة. الاستثناء القديم لغياب نسخة يخص عملية F السابقة ولا يُعاد استعماله هنا.

## 7. المتبقي والبوابات

الخطوة اليدوية التالية قراءة الفحص الجديد فقط من SQL Editor للمشروع الأصلي المحدد، ثم إرسال صف العقد المنقح. إذا baseline_matches=false أو ظهر error نتوقف لتشخيص الفرق دون كتابة. حتى عند true تبقى شروط النسخ/الاسترداد والمزود والتطبيق الفعلي للترحيل والتحقق بعده والخدمة المغلقة وإثبات توافق الواجهة خطوات لاحقة مستقلة؛ لا يجيز هذا الملف تجاوزها.

دورة نسخ/تصدير/restore وإعادة تطبيق الإغلاق والتعطيل والموافقة والحذف من دليل مستقل لم تُنفذ؛ شاهد اللقطة السابق ليس restore كاملة. النسخ التي نديرها يومية مشفرة بتداول سبعة أيام ونسخة قبل التغيير، ونسخ المزود تحتاج تحققًا مستقلًا. launch_gate تحمي البدء فقط ولا تكفي لعزل قراءة قاعدة مستعادة. O108 والمصادر والترخيص والمراجعة والخلفية والمعايير وMarker، وruntime والعامل والجدولة والمراقبة والنشر بوابات مستقلة. غير المؤقت محجوب والبوابة مغلقة والقبول التجريبي الحي غير مكتمل.
