## 1. الانحرافات

لا تغيير دلالي لاختبارات قائمة، ولا تجاوز لميزانية16 ملفًا. التنفيذ يستخدم14 ملفًا؛ لا مكوّن footer إضافي لأن إدراج رابط في التذييلين الموجودين كافٍ. فحص TypeScript أولي قبل توليد أنواع المسارات أظهر أنواعًا مولّدة قديمة وتبعية PGlite ناقصة في البيئة؛ تمت تهيئة البيئة دون تعديل manifest/lock.

## 2. النطاق المنفذ والمستبعد

صفحة `/{locale}/credits` ثابتة EN/AR من سجل typed؛ صور فعلية فقط دون تكرار صور/مصغرات، ومراجع علمية ورسومات أصلية، وروابط تذييل مع اللغة للصفحات العادية و404. اعتمادات النتائج الأصلية محفوظة مؤقتًا باختيار المالك الصريح بعد شرح تعارض حراس DOM؛ تحديثها خارج نطاق هذه الدفعة النهائي. لا NIH terms جديدة، ولا صور/فحوص أو تغييرات محرك/حالات/تقييم/شروط/حسابات/DB. لم تُفتح روابط المصادر أو معاينة مستضافة.

## 3. حسب المهمة

- RAD-045: منفذة للمراجعة؛ تبقى review/waiting_on owner، لا done قبل الدمج والدليل المناسب.
- O102: أسماء المصادر والمؤلفين والتراخيص المثبتة والتعديلات وحدود الأدلة في الصفحة. استشهاد NIH الكامل ورابط التحميل وإقرار المزوّد محفوظة؛ بيانات RadCase الأصلية لم تتغير.

## 4. المشترك وفحص التوسع

اقتُرح تحديث ResultImage من السجل، لكن فحص check كشف أن حراس scene-dom الثمانية تشمل نص الاعتماد. رُدّ الملف إلى نسخة main لحفظ الحراس دون تحايل أو إعادة توليد. عُرض خيار استثناء لتحديث مفاتيح result فقط وميزانية23 ملفًا، لكن المالك اختار صراحةً «إكمال الصفحة وإبقاء اعتمادات النتائج مؤقتًا». لذلك بقي النطاق14 ملفًا دون استثناء أو تجديد بصمات. فشل تشغيل أول بسبب استيراد رابط Next في بيئة الحراس، وبعد استبداله برابط HTML ظهرت فروق البصمات المتوقعة؛ لم تتغير الاختبارات. روجع عرض EN/AR بصريًا؛ ثُبّت اتجاه أبعاد الصور داخل النص العربي بعزل LTR، ثم أُعيد check والبناء والتصدير والتدقيق المحلي على النسخة النهائية.

`creditFor` يطابق مفتاح الصورة وسلسلة registryIds كاملة؛ `usedImageCredits` يستمد الأصول والفحوص من سجل الحالات ويزيل التكرار بين السيناريوهات. فشل واضح عند غياب سجل للصفحة، دون حذف الاعتماد الموجود تحت النتائج؛ تكامل عرض النتائج مؤجل باختيار المالك. إضافة فحص أو أصل لا تحتاج قائمة JSX أو عددًا ثابتًا. النصوص LocalizedText ومفاتيح الرسائل متطابقة، وتُستخدم آلية اللغات الحالية. لا مخزن دائم أو استعلامات أو خدمات أو مكتبات جديدة أو تحليل Markdown وقت التشغيل. لا يحتاج التذييل مكوّنًا جديدًا لإضافة رابط واحد.
