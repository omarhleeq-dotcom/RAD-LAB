## 4. المشترك و Scale

لا تغييرات مشتركة. حدود المراجعة قائمة: صفحة 20،200 بند و 128KiB، ومسودة حالية واحدة لكل حساب/مجموعة في الذاكرة؛ إعادة تحميل الصفحة تمحوها. الكتالوج مشتق من السجل، ويحتاج بحثًا و paging خادميين عند النمو؛ snapshot الداخلي≤1000 اصطناعي فقط. لا نقل تجميع fixture إلى عميل الخدمة، ولا ضمان 120 مستخدمًا من هذا الجرد. تعدد المسودات واللغات/الأدوار الإضافية يحتاج عقدًا وإصدارًا ونطاقًا مستقلًا. بوابات قياس FREE و receipts و Practice والنسخ اليدوية باقية في الخطة، دون تغيير سقوف أو مهل.

## 6. ما فُحص وما لم يُفحص

- قراءة جرد المصدر والعقود والاختبارات والتقارير مقابل نطاق الخطة، والتحقق من Git و main والرأس وحالة PR. لا اعتماد على SHA التسليم دون جلب.
- الاعتمادات المحلية كانت ناقصة esbuild؛ نجح `npm ci --ignore-scripts` من القفل دون تعديل package/lock. لا سر أو إعداد مزود تغير.
- شُغلت أداتا `--serve` القائمتان، وأُخذت وثيقة P1 مع locale=ar و P2 مع locale=en عبر curl: HTTP200، و Cache-Control:no-store و CSP connect-src 'none'، ووجود bundle والعنصر الجذر. bundling نجح بحارسي browser imports القائمين؛ أُوقف الخادمان بعدها. هذا فحص تشغيل/HTTP في البيئة الحالية **ولا ينفذ React أو تفاعلات أو axe أو فحص هاتف**. الملفات المؤقتة `/tmp/rad085-readiness-*` محلية وليست أدلة ملتزمة مطلوبة للتشغيل.
- فحوص الدفعة التوثيقية: `npm run docs:check -- --base origin/main` و`npm run status:check -- --base origin/main --require-previous` و`git diff --check`؛ نجحت الفحوص الثلاثة، و docs:check بلا أخطاء أو تنبيهات مراجعة. فحص الحالة يتحقق من التنظيم واستمرارية المعرّفات فقط.
- لم يُعد check/build أو اختبارات منتج أو مصفوفات المتصفح/الأسر أو docs:test: لا تغيير متعلق يستدعي إعادة نجاحها. نتيجة 198 ملفًا و 2910 اختبارات والبناء وتدقيقات المشهد/mixed/P1 وصفحات الفحوص **أدلة تاريخية للنسخة السابقة في تقرير المشهد فقط**، وليست نتائج هذه الجلسة. لا لقطات جديدة أو تغيير لاختبارات/مهل/حراس.
- لم تُفحص قاعدة أو خدمة أو هاتف أو أداء/تزامن حي أو CI/نشر/طب؛ لا SQL أو migrations/RLS/checks أو اختبارات database جديدة أو RPCs أو ربط حي أو Supabase/variables/PILOT_SCHEMA_VERIFIED/launch_gate/CONSENT_VERSION أو عامل أو hosted preview.

## 7. المفتوح وتسلسل المتبقي

أولًا مراجعة المالك المحلية و**هاتفه الفعلي** ثم معالجة ملاحظاته والتحقق المناسب للتغيير. بعد ذلك فقط جلسة أخيرة واحدة تجمع كل SQL واختبارات database الجديدة؛ لم تبدأ هنا. القاعدة تتبقى بالتفويض والرفض المباشر وفترات العضوية والرموز والوقت الخادمي و RLS/ACL والتزامن و snapshot والنسخ والموافقة. الربط يتبقى بالحفظ والإسناد الحقيقيين و idempotency ومصالحة ACK وإبطال cache؛ أسماء DTO ليست RPC/schema نهائية.

العامل والصورة المتطابقة مع evaluator/case ومسار candidate→pending→installed والمقياس والمراجعات المستقلة و O108 والمصادر والرخص والمحاكي و Marker والنسخ/restore والمراقبة/STOP والتكلفة والحمل والأداء والقبول بوابات منفصلة قبل إطلاق. Cloud Run ومجموعات المشرف وحد 7 أيام للكتابي ومرحلة الصور اللاحقة محفوظة. ملاحظة تكرار تعطيل/حذف الحسابات خارج النطاق. PR #137 نفسه Draft؛ لا ready/merge/auto-merge أو بديل إذا أُغلق/دُمج دون إبلاغ المالك أولًا.

## 8. قائمة المالك المحلية وبرومبت المتابعة وسؤالا AGENTS

**مراجعة المالك مطلوبة في هذه النقطة، ولم تحصل أو تُقبل بعد.** هذه مراجعة للنطاق المحلي، وليست قبولًا للربط أو SQL أو الإطلاق.

من جذر المستودع مع اعتمادات القفل، شغّل في طرفيتين:

```sh
node scripts/qa/rad-085-supervisor-audit.mjs --serve
node scripts/qa/rad-085-authoring-audit.mjs --serve
```

افتح عنوان loopback الذي يطبعه كل أمر، مع `?locale=ar` ثم `?locale=en`. لا تشغّل التدقيق دون `--serve` لمجرد المراجعة؛ لا حاجة إلى Playwright/axe لهذا الوضع. الثيم الافتراضي داكن؛ للفاتح محليًا من console المتصفح `document.documentElement.dataset.theme = 'light'`، وللداكن `'dark'`. لكل أداة fixtures مستقلة، وإعادة التحميل تمحو الذاكرة. لا تعتمد تغيير P1 لينتقل إلى P2.

1. **P1:** تعيين/سحب من حساب المالك؛ من المشرف أنشئ مجموعة ودوّر الرمز، ثم من الطالب اطلب الانضمام؛ ارجع للمشرف للقرار ثم جرّب مغادرة/إنهاء بتأكيد وإلغاء، وتبديل الحساب ومسح العرض/الرمز وصفحات الطلاب والنتائج وصياغة الموافقة.
2. **mixed:** من أداة P2 اختر مجموعة ثم أنشئ mixed، وأدخل توكنات هندسية غير سريرية مثل ALPHA/BETA مع بيانات تأليف صريحة أنها اصطناعية غير معتمدة. جرّب الأخطاء والحفظ والترتيب ومعاينة MCQ وجزء قائم؛ تحقق من غياب المفتاح وحقول المؤلف ومن مسح الاختيارات بعد الإغلاق.
3. **full-practical:** أنشئه بمجموعة أخرى أو أعد تحميل P2 لمسح الذاكرة (مسودة واحدة لكل مجموعة). اختر حالتين قائمتين، وحرك المشهد والضوابط وتنقل بين البنود ثم أغلق وأعد الفتح؛ راجع فصل المسارين وعدم ظهور حل/درجة أو تعريض/حفظ جواب خدمة.
4. **الإسناد والفشل:** احفظ المسودة، راجع اسم المجموعة والنسخ والعدد والصفحات 20/4 ثم ألغِ وأكّد. جرّب بطء/إلغاء وتعارض وسحب وانتهاء وتبديل الحساب، دون اعتبار الإيصال إسنادًا حقيقيًا.
5. **الهاتف:** على هاتفك الفعلي وبوصول محلي تعتمده أنت، افحص AR/EN والثيمين، اللمس والسحب والتمرير وحجم النص ولوحة المفاتيح والتركيز والتنقل والإغلاق والتبديل. سجّل ما فُحص والعيب واللغة والثيم والجهاز؛ إن لم يتح وصول محلي للهاتف فالبند يبقى غير مفحوص، ولا يُستبدل بعرض 390 أو لقطة حاسوب. أوقف الأداتين بـ Ctrl-C بعد المراجعة.

برومبت المتابعة: «تابع RAD-085 على PR #137 نفسه Draft وفي نفس checkout دون worktree/subagents. اقرأ AGENTS والسياق وأحدث main والرأس والحالة وتقرير الجاهزية. إن أُغلق أو دُمج توقف وأبلغني قبل بديل. سجّل مراجعة المالك والهاتف بأدلتها وحدودها، وعالج ملاحظاته ضمن هدف وميزانية معلنين. لا تبدأ SQL قبل انتهاء المراجعة ومعالجة الملاحظات؛ كل SQL واختباراته الجديدة في الجلسة الأخيرة المجمعة فقط بأمرها. لا ربط حي أو عامل أو نشر أو hosted preview أو ready/merge/auto-merge».
