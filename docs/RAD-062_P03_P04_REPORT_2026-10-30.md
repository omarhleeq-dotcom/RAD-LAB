## 2. المنجز والمستبعد

### P3

M03 تضيف سياسة مؤصدرة وحسابًا خادميًا للبايتات المتسلسلة يشمل المسودة الحالية والمراجع والنسخ وحزم المراجعة والمنشأ والمرشحين، بلا خصم لضغط TOAST. أقفال المعاملة تسلسل نمو التأليف عبر الكتّاب والمسودات، مع تحقق بعد الكتابة يشمل المنشأ الذي يضيفه الخادم. حدود3مسودات عبر المجموعات و10نسخ محتفظة و64KiB للوثيقة مع refs ولحزمة النسخة، إنذار4MiB والسماح بالوصول إلى8MiB ورفض النمو بعده. المحتوى القديم لا يقص؛ v1 تحتفظ بتعريفات دوالها وتواقيعها وACL وتظل قابلة للاستدعاء؛ guards الجداول تطبق سياسة السعة الجديدة على كتابات v1 وv2 معًا حتى لا يستطيع مسار قديم تجاوز الحصة. بيانات v1 المحتفظة تدخل الحساب دون قص أو backfill.

عتبات القاعدة عشرية:300MB إنذار،350MB مراجعة وتقليل الدفعات،400MB وقف النمو والبدء الجديد مع حجز الذروة؛ لا ربط لها بحفظ/تسوية محاولة قائمة. مخزن الحجز خاص، مرتبط بتفاصيل المحاولة ليزول معها؛ دمج البدء لاحقًا في P4/P6. لا قناة إنذار جديدة مفعلة أو قياس حي.

التنظيف استدعاء خاص صريح فقط، dry-run افتراضي،≤100مرشح مفحوص في الدفعة، وعمر أكبر من30يومًا، دون حذف الحالية وأحدث3. إعادة فحص بعد قفل المسودة والنسخة، وحماية كل روابط النشر والمراجعات والإسناد والمحاولات التابعة لها والحجوز الحقوقية/الطارئة. يحافظ تحفظيًا على أي مرشح أو حزمة مراجعة أو منشأ، حتى يراجع التخلص من دليلها؛ لا يفترض أن غياب FK يعني غياب حق. FK جديدة غير معروفة توقف التنظيف. لا scheduler ولا تشغيل تلقائي أو تنظيف حي.

### P4

بدأت P4 **بعد** دفع commit P3 `962d30e` بنجاح. M04 وعقود v2 والجسر والمتوقع الخادمي تتحقق من K الصحيح≤N ومن تساوي نقاط الاختيار الواحد بأعداد عشرية دقيقة، وتحسب maximum من K لاN مع جميع البنود الثابتة. لا Topic/Difficulty. [القرار الحاكم](DECISIONS.md#random-question-pool-owner-2026-10-30) محفوظ.

`pool_start_v2 / pool_resume_v2` primitive خاصة للمحاولة التي ربطها الخادم؛ تنفذها M06 ضمن **المعاملة نفسها** لإنشاء session وحجز start operation. ليست API دورة حياة مستقلة ولا تمنح تشغيلًا هنا. الأقفال الخادمية تسلسل البدء/replay/resume؛ تحفظ معرّفات المختار وترتيب الأسئلة والخيارات فقط في pool_selections_v2. تفاصيل المحاولة ومفاتيحها وspecs تحوي المختار والبنود الثابتة فقط؛ DTO الطالب لا تحمل privateItems أو المفتاح أو الحوض أو بيانات غير المختار أو منشأ المؤلف.

سحب K منN دون إرجاع عبر ORDER BY random() محدود بـ200بند، وخلط الأسئلة والخيارات افتراضي، مع shuffleOptions=false لكل سؤال. الكتابي كله ثابت للجميع وخارج السحب، مرتب بترتيبه الأصلي بعد الأسئلة المختارة. K=N يعطي الجميع البنود نفسها مع ترتيب مسحوب؛ resume لا يسحب ثانية. حذف التفاصيل عند النهائي/void/المحو يحذف الاختيار والحجز تلقائيًا وفق FK، دون تغيير دوال الاحتفاظ القديمة.

fence خالية من الهوية/النص تحفظ أن أول محاولة بدأت وأي version بدأت؛ تبقى بعد احتفاظ المحاولات. يمنع الخادم نسخة بديلة أو إسنادها/بدءها بعد أول محاولة ولو أُنشئت قبل البدء، ويحمي سباق publish/start بقفل واحد. الوثيقة المنشورة ثابتة؛ البديل قبل بدء أي محاولة نسخة جديدة وفق قرار المالك، دون تحديث محتوى النسخة نفسها. حجز الذروة محسوب خادميًا من snapshot المختارة وسقف الكتابي ومعامل3 ومساحة receipt؛ رفض البدء عند ذروة≥400MB، بينما replay لاستحقاق قائم لا يعيد admission. لا يدّعي هذا قياس السعة على حمل120طالبًا أو اكتمال M06/الgrader.
