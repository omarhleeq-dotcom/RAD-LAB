- **انحراف إجرائي واحد**: بقرار المالك الصريح أُرسلت ثلاث UUID للحسابات في المحادثة لتعبئة استعلام التحقق (استثناء لإجراء واحد من قاعدة «لا UUID في المحادثة»)؛ لم تُكتب في Git أو التقارير.
- دُفع كل شيء إلى `assess-local-operations` (رأس #96، Draft) بإذن المالك بدل فرع الجلسة، لتجنب مسودة مكررة.

## 2. المنجز والمستبعد

**المنجز (إفادات المالك + فحوص محلية):**
1. بناء ورفع صورتي `assess-trial` و`assess-trial-tools` بـdigest مثبت، وJob تثبيت وJob عامل مقيد بـretries 0 وحارس 0 داخل الصورة.
2. إثبات الهويات الثلاث بأداة المالك (4 PASS، أزواج متبادلة، طالبان مختلفان).
3. نطاق خامل ثم مفعّل (controller واحد، مالك + A + B، نسختان).
4. تثبيت نسختي المحتوى (visible وhidden) عبر الأداة الموثوقة، وإسنادهما لـA فقط.
5. موافقة A على v2 بنفسه.
6. نافذة حية: visible بدأ/حُفظ/سُلّم وصُحح **5/10**؛ hidden حُفظ فيه السؤال الأول وانتهت مهلته وصُحح بالخادم وبقيت درجته محجوبة؛ B لا يرى شيئًا؛ لا محاولة ثالثة.
7. إغلاق كامل: بوابة، LOGIN العامل، جلسات 0، وإسنادان مغلقان نهائيًا، ولا executions جارية.

**المستبعد/لم يُنفذ:** زر إغلاق في الواجهة (قرار لاحق)، جدولة أو تشغيل دائم، تعطيل النطاق بعد التجربة، اختبار انقطاع شبكة فعلي وتعدد أجهزة، مراقبة وإنذارات، إلغاء Supavisor/cache مثبت، نسخ احتياطي/استعادة، دمج #96 (المالك أجلّه حتى اكتمال Assess).
